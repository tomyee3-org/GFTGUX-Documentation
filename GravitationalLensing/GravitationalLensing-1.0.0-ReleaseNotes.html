Release Status

Version 1.0.0 concludes a Grok kickoff followed by six rounds of independent review by Codex and Copilot. The reviewers checked the thin-lens equation and its point-mass and SIS+shear specializations; image multiplicity inside the restricted shear domain; forward ray geometry; field-of-view and sampling contracts; provenance; Help accuracy; Version/Build synchronization; and the regression suite from both the canonical tests/ directory and a flattened layout. Codex and Copilot both report that no release-blocking defect remains. The program is suitable for student use within the tutorial scope and limitations described below.

Major Improvements in This Release

  • Standalone Python tutorial (no Jupyter) with seven modes that follow a beat sequence: forward rays, point-mass ring and double, extended source, critical curve versus caustic, SIS+shear diamond, arcs, and SIS convergence.
  • Verified point-mass images \(\theta_\pm = \tfrac12\bigl(\beta \pm \sqrt{\beta^2+4\theta_E^2}\bigr)\), \(\det A = 1-(\theta_E/\theta)^4\), and SIS \(\kappa=\theta_E/(2|\theta|)\) with the \(\kappa=1/2\) circle on the Einstein ring.
  • Restricted external shear to \(|\gamma|<1/3\) so the diamond stays inside the SIS pseudo-caustic and the lesson only promises the 1-, 2-, and 4-image regions.
  • Replaced backward ray shooting with a forward thin-lens bundle: incoming slope, physical deflection toward the mass, outgoing slope, hit test at the observer.
  • Adaptive field of view that contains the Einstein ring, mapped half-light contour (point-mass), and the conservative SIS+shear bound \((|\beta|+R_e+\theta_E)/(1-|\gamma|)\).
  • Sampling contract: the grid is built from the unlensed source scale; each compact lensed image must then span at least 0.8 grid interval or the run is rejected. Extreme offsets that would erase the demagnified member of a point-mass double are outside the teaching domain.
  • Automatic grids stop at 401 pixels. Analytic visibility and domain guards run before the mesh is allocated.
  • False-colour maps are labeled as such so students do not read chromatic dispersion into gravitational deflection.
  • Provenance sidecars record mode, version, build, effective FOV, \(n_\mathrm{pix}\), and the lens/source parameters needed to reconstruct a figure.
  • Reproducible BUILD_ID hashed from the four core modules, with python main.py --sync-help writing the Help #version_build element.

Test Suite Growth

The kickoff suite froze Einstein-radius units, the two-image formula, \(\det A=0\) on the ring, SIS \(\kappa=1/2\), and Help/CLI version agreement. Six audit cycles added image-count topology, signed \(\beta_y\), analytic critical-curve closure, FOV and sampling contracts, off-axis arcs containment, kappa Einstein-circle resolution, BUILD_ID isolation in a temporary directory, and mode-specific provenance. The release suite contains 55 tests. All pass under MPLBACKEND=Agg from GravitationalLensing/ and from GravitationalLensing/tests/.

Known Limitations

  • Intended for education, not research-grade lens modeling, source reconstruction, or cosmological parameter estimation.
  • \(|\gamma|\ge 1/3\) (naked cusps and a three-image region) is rejected by design.
  • Image counts within \(10^{-4}\,\theta_E\) of a fold or cusp are not a promised teaching output.
  • The 0.8-interval image-plane rule is a visibility floor. Morphology of a highly magnified or highly compressed image is under-sampled on purpose.
  • A source many Einstein radii off axis cannot show both members of a point-mass double on a uniform teaching grid and is rejected. Raising --n_pix is not offered as a general remedy.
  • Gaussian sources have infinite support; the field is guaranteed only through the mapped half-light contour (point-mass) or the SIS+shear norm bound.
  • Distances are a fixed 1 Gpc / 2 Gpc cartoon. Changing cosmology is not an exercise.
  • The Help file loads MathJax from a public CDN. Offline, prose and unrendered TeX remain readable.

Known Minor Maintenance Items

  • Packaging still requires python main.py --sync-help before a Help-bearing zip; tests detect drift after the fact.
  • Near-caustic image counts use a documented exclusion buffer rather than a global root enumerator.
  • Repository-level checking that related-program Help links resolve is outside this package.
