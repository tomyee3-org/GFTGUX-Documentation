Description

What does a distant galaxy look like when a foreground galaxy acts as a lens? GravitationalLensing explores this through one master equation — the thin-lens mapping \(\boldsymbol\beta=\boldsymbol\theta-\boldsymbol\alpha(\boldsymbol\theta)\) — and seven interactive modes that build our intuition step-by-step. From simple point-mass deflections to extended sources and sheared geometries, the module investigates how light bundles wrap around massive objects to create arcs, rings, and multiple images.

The narrative spine of the lesson is simple: the photograph is decided entirely by where the source sits relative to the caustic structure. In a pure point-mass lens, the caustic is collapsed to a solitary point at the origin, yielding either a perfect ring or a strict pair of images. Once we transition to a singular isothermal sphere (SIS) with external shear, that point blossoms into a diamond caustic with four folds and four cusps, turning image multiplicity into a dynamic map of source position.

Note: Singular Isothermal Sphere is a standard theoretical model for a galaxy's mass distribution. Its smooth, gradual density drop-off creates a flat rotation curve and a constant deflection angle, serving as the baseline model for multi-image galactic lenses.

What this program is not. It does not integrate null geodesics in the Schwarzschild metric (that is PhotonOrbit). It does not fit a mass model to a Hubble image. The thin-lens deflection is applied in one plane. Galaxy-scale strong lensing is the intended domain; a black-hole silhouette is not.
False colour. Modes point, blob, critical, arcs, and kappa paint intensity or convergence with a colour map. Those colours are a display scale, not the spectrum of the source. Gravitational deflection is achromatic: a point-mass or SIS lens does not split light into rainbows the way a glass prism or the atmosphere can. A white galaxy stays white; the program has simply chosen a palette so a faint arc is visible on a screen.
Reading this page. Equations are rendered by MathJax from a public CDN. Without a network connection the raw \(\LaTeX\) remains visible as text. The program itself needs no internet access.

Before the first run

Unpack the program zip so you have a folder named GravitationalLensing that contains main.py. Open a terminal in that folder. You need Python 3.10 or newer with NumPy and Matplotlib. If you do not already have that environment, follow the project-wide GFTGUX Python Setup Guide (the link is the documentation repository root so you can download the whole tree with the green Code button, without a GitHub account). On Linux, do not install packages into a system Python. Then:

python main.py --version
python main.py --mode rays

Every command on this page assumes that working directory. Even values of --n_pix are rounded up to the next odd number so a pixel sits on the optical axis.

Beat 0 · Raytraced views

Unlike a glass lens—which bends light most strongly near its rim—a point-mass gravitational lens does the exact opposite: rays that skim close to the mass suffer extreme deflection, while rays passing far out are barely nudged. Furthermore, an astronomical observer does not sit at a camera-lens focal plane; instead, we only receive those specific light rays whose bending happens to land precisely on our line of sight.

Run the command to explore these trajectories yourself: 

python main.py --mode rays

Both panels trace rays forward from a single source (\(\boldsymbol\beta\)) at \(x = 0\) toward an observer at \(x = 2\), with a point-mass lens situated at \(x = 1\). Because gravity is purely attractive, every trajectory experiences a single sharp kink toward the lens:

  • Top Panel (On-Axis): Symmetry makes every azimuth equivalent. There is a precise impact angle where the deflection bends the ray right into the observer, forming the continuous Einstein ring (traced by the converging red rays). Blue rays miss the observer entirely.
  • Bottom Panel (Off-Axis): When the source is shifted off-axis (\(\boldsymbol\beta_y > 0\)), circular symmetry breaks. The focusing condition is met by exactly two distinct rays—one passing outside the ring, one inside—resulting in two separate images on opposite sides of the lens.

Distances in these plots are schematic (\(D_l = D_{ls} = 1\), \(D_s = 2\)), so the vertical axis represents angles in radians (with a default \(10^{12}\,M_\odot\) lens yielding \(\theta_E \sim 10^{-5}\)). The lower panel utilizes the signed value of --beta_y (positive above the optical axis, negative below).

The core concept that the rest of this module makes quantitative is simple: an observer does not see a lens like a camera sees an object. We see whatever directions happen to satisfy the lens equation. Everything from a perfect Einstein ring to a complex four-image quad is simply a different geometric manifestation of that single equation at work.

Beat 1 · Play with a point mass

Let's translate our geometric setup into an image on the sky. First, place the source slightly off-axis to break symmetry and produce two distinct image arcs rather than a ring:

python main.py --mode point --logM 12.0 --beta_x 0.5

Next, center the source precisely on-axis to see what appears:

python main.py --mode point --logM 12.0 --beta_x 0.0 --beta_y 0.0

On-axis symmetry causes the images to merge into a complete Einstein ring. Try shifting the source vertically instead (e.g., setting \(\beta_y = 0.5\)) to watch that ring split back into two opposing images.

Now, scale up the lensing mass to \(10^{12.5}\,M_\odot\) while displacing the source in both coordinates to observe how the overall geometry expands:

python main.py --mode point --logM 12.5 --beta_x 0.3 --beta_y 0.3

The Physics: Einstein Radius & The Lens Equation

The interactive commands above are numerical solutions to the fundamental equations governing point-mass lenses:

Point-mass Einstein radius
\[ \theta_E = \sqrt{\frac{4GM}{c^2}\,\frac{D_{ls}}{D_l D_s}} \]
Lens equation
\[ \boldsymbol{\beta} = \boldsymbol{\theta} - \boldsymbol{\alpha}(\boldsymbol{\theta}), \qquad \boldsymbol{\alpha}(\boldsymbol{\theta}) = \theta_E^2\,\frac{\boldsymbol{\theta}}{\lvert\boldsymbol{\theta}\rvert^2} \]

Implementation Notes: A \(10^{12}\,M_\odot\) lens halfway to a source at 2 Gpc yields \(\theta_E \approx 2''\). These distances are illustrative choices selected to keep Einstein radii conveniently sized in arcseconds; they do not represent a true cosmological model.

Vector \(\boldsymbol{\beta}\) represents the true angular position of the source; vector \(\boldsymbol{\theta}\) is the observed angular position of an image; and vector \(\boldsymbol{\alpha}(\boldsymbol{\theta})\) is the reduced deflection angle. Constants \(G\) and \(c\) use SI units, mass is specified via --logM as \(\log_{10}(M/M_\odot)\), and the compact-source width is fixed at \(0.08''\). When you increase --logM, the program automatically expands the field of view so the resulting ring is never clipped.

\(D_{ls}\), \(D_l\), and \(D_s\) are the angular-diameter distances from lens to source, observer to lens, and observer to source, respectively. For objects in ordinary Euclidean space, these would be ordinary distances obeying a simple linear sum (\(D_s = D_l + D_{ls}\)). However, on cosmological scales, spacetime expands while light travels toward us. Consequently, standard Euclidean geometry breaks down, and multiple distinct definitions of distance arise—such as comoving distance, proper distance, luminosity distance, and angular-diameter distance.

The angular-diameter distance \(D_A\) is defined as an object's physical transverse size divided by its observed angular size in radians (\(D_A = L / \theta\)), and a simple additive relationship does not generally hold between \(D_l\), \(D_{ls}\), and \(D_s\).

Beat 2 · Why two images

A point-mass lens never produces just one image of an off-axis source, nor does it ever produce three. Understanding why provides a vital foundation before moving on to more complex lenses.

python main.py --mode point --beta_x 1.0 --beta_y 0.0

The two resulting images appear at \(+2.579''\) and \(-1.579''\) along the source direction. The white cross at \(+1.0''\) marks the source's position on the source plane—where the object would reside if space were flat and empty of gravitating mass. Crucially, this is a geometric reference coordinate rather than a spot you'll see a photon coming from: no light ray travels straight from that cross to the observer. Instead, light leaves the source in two different directions, gets deflected by the mass, and arrives at your telescope as the two visible images. (If you save the figure using --outdir, exact image positions and signed magnifications are written to a provenance file.)

For a source on the \(x\)-axis at angular distance \(\beta\) from the lens, the two image radii are given by the analytic double:

Analytic double
\[ \theta_\pm = \frac{1}{2}\left(\beta \pm \sqrt{\beta^2 + 4\theta_E^2}\right) \]

\(\theta_+\) lies outside the Einstein ring, while \(\theta_-\) lies inside on the opposite side of the lens, forming a mirror-reversed image. When the source is on-axis (\(\beta = 0\)), both collapse to \(\pm\theta_E\) to form the complete Einstein ring, represented by the cyan dashed circle.

Why always two images? In the equation above, the term under the square root (\(\beta^2 + 4\theta_E^2\)) is strictly positive for any finite \(\beta\) and \(\theta_E > 0\). Because a quadratic equation with a positive discriminant always has exactly two real roots, a point-mass lens can never have just one root or zero roots for a displaced source—it must always produce a pair. (By contrast, the sheared lens in Beat 5 will show how a non-circular potential changes this topology, yielding one, two, or four images depending on where the source sits relative to the caustics.)

Beat 3 · An extended blob

Now, replace the compact source with an extended elliptical Gaussian galaxy, leaving the lens unchanged. Try exploring these variations:

python main.py --mode blob --beta_x 0.00 --beta_y 0.0 --r_eff 0.25
python main.py --mode blob --beta_x 0.15 --beta_y 0.0 --r_eff 0.25
python main.py --mode blob --beta_x 0.15 --beta_y 0.8 --r_eff 0.20 --q 0.60 --phi 30.0

When the extended source is centered on-axis, it no longer forms two isolated dots, but instead smears out into a thick ring. This happens because every azimuth of the galaxy's light satisfies the on-axis lens equation simultaneously, with the near and far edges mapping to slightly different radii. Shift the source off-axis, however, and that ring breaks into two opposing arcs—literally the same geometry as the lower panel of --mode rays, but now rendered as a false-color photograph of an extended object rather than a sketch of individual rays.

For a pure point-mass lens, the source plane has only one distinguished point: the origin. A source placed directly on it becomes a ring; a source anywhere else becomes two images. The set of points in the source plane where the lens mapping changes its multiplicity is called the caustic curve—which, for this point mass, is only a single point at the origin.

Beat 4 · Caustic and critical curves

The lens mapping sends each sky position \(\boldsymbol{\theta}\) to a source position \(\boldsymbol{\beta}(\boldsymbol{\theta})\). The Jacobian matrix of that map is \(A = \partial\boldsymbol{\beta}/\partial\boldsymbol{\theta}\), and its determinant defines the signed magnification:

Signed magnification
\[ \mu = \frac{1}{\det A} \]

The sign of \(\mu\) indicates image parity (where negative parity represents spatial mirroring rather than negative brightness), while its absolute value \(\lvert\mu\rvert\) gives the factor by which observed flux and area are amplified. In the ideal limit of a point source, \(\lvert\mu\rvert \to \infty\) along the critical curve; finite sources like our Gaussian blobs experience a smooth, finite peak magnification.

Where \(\det A = 0\), the local geometric stretch diverges for a point source. The set of all such points on the sky forms the critical curve. Map that exact set backward through the lens equation into the source plane, and you get the caustic. A caustic is not a physical structure floating in space; it is a geometric curve in the source plane marking the exact boundaries where the lens mapping changes its image multiplicity.

Two planes. The critical curve lives in the image plane (the sky). The caustic lives in the source plane. The lens equation maps one into the other; they are fundamentally distinct curves.

For a point-mass lens, the Jacobian determinant simplifies to:

Point-mass Jacobian
\[ \det A = 1 - \left(\frac{\theta_E}{\lvert\theta\rvert}\right)^4 \]

The zero-determinant set is the Einstein circle. Mapped backward, that entire circle collapses down to a single point at \(\beta = 0\). On that point, you get a complete ring; off it, exactly two images. For a point-mass gravitational lens (such as a star or a compact black hole), every possible image configuration reduces to these two simple topological outcomes.

Mode critical displays a three-panel dashboard simultaneously: the false-color image plane with the critical curve overplotted, the source plane marking the caustic as a star at the origin, and a side-view ray trace. This side view is our familiar thin-lens unwrapping from Beat 0 (not a full Schwarzschild geodesic), where red rays reach the observer and blue rays miss. Note that because this diagram is a 2D slice through a 3D geometry, motion in \(\beta_x\) points into or out of the page—use --beta_y to shift the source position vertically[cite: 8, 9].

python main.py --mode critical
python main.py --mode critical --beta_y 0.4
Leave the mass alone for this beat. Changing --logM only resizes a self-similar circle; the default mass is already ideal for the figure. The coordinate that changes what you see is the source position, represented in the side view by --beta_y.

Beat 5 · Break the symmetry

Real lensing galaxies are neither pure point masses nor perfectly circular halos. A standard teaching model combines a singular isothermal sphere (SIS) with a touch of external tidal shear \(\gamma\):

SIS + shear deflection
\[ \boldsymbol{\alpha} = \theta_E\,\hat{\boldsymbol{\theta}} + (\gamma\,\theta_x, \, -\gamma\,\theta_y) \]

Breaking this circular symmetry transforms the critical curve into an oval on the sky, while the point-like caustic in the source plane opens up into a diamond featuring four smooth folds and four sharp cusps. As long as the source remains within a given region without crossing a caustic boundary, moving it merely shifts the existing images.

Because the SIS mass profile is singular at the origin, a second boundary appears: the pseudo-caustic, represented by the dashed circle of radius \(\theta_E\) in the source plane. When the source moves outside this circle, only one image remains visible because the second image has merged into and vanished within the central singularity. (Real galaxies with finite-density cores behave differently, but in this idealized model, image counts shift across both true caustics and the pseudo-caustic.)

To keep the diamond safely inside the pseudo-caustic—avoiding complex "naked cusp" topologies—the program restricts shear to \(\lvert\gamma\rvert < 1/3\). The default value \(\gamma = 0.25\) provides a clean, textbook demonstration of these regimes.

Beat 6 · Arcs on the diamond

Now, replace the point source with an extended elliptical galaxy, keeping the SIS + shear lens configuration (defaulting to --gamma 0.25 --q 0.60 --phi 30.0). Depending on where the extended source sits relative to the caustic diamond, the lensed image transitions from stretched arcs to broken rings:

  • Diagonal fold: When the finite source straddles a diagonal fold, a merging image pair stretches into a long, bright arc feature.
    python main.py --mode arcs --beta_x 0.18 --beta_y 0.30 --r_eff 0.14
  • Short-axis cusp: Straddling the cusp near \(0.519''\) causes a crowded image triplet to blend into a broad, magnified patch (compare this directly with the caustic layout from Beat 5).
    python main.py --mode arcs --beta_x 0.55 --beta_y 0.00 --r_eff 0.14
  • Intermediate position:
    python main.py --mode arcs --beta_x 0.18 --beta_y 0.00 --r_eff 0.25
  • Centered with shear: Parking the source at the origin under default shear produces four distinct arcs wrapped around the oval critical curve—reflecting broken symmetry rather than a true ring.
    python main.py --mode arcs --beta_x 0.00 --beta_y 0.00 --r_eff 0.20
  • Centered without shear: Removing the external shear restores the perfect circular symmetry needed to form a complete, unbroken circular Einstein ring.
    python main.py --mode arcs --gamma 0 --beta_x 0 --beta_y 0 --r_eff 0.20

Beat 7 · What \(\kappa\) is

Convergence (\(\kappa\)) is the projected surface density of a lens in units of the critical density required for lensing:

Convergence
\[ \kappa(\boldsymbol{\theta}) = \frac{\Sigma(\boldsymbol{\theta})}{\Sigma_{\mathrm{crit}}} \]

Convergence quantifies how efficiently a localized mass distribution focuses light rays. For a singular isothermal sphere (SIS), the convergence falls off as inverse radius: \(\kappa = \theta_E / (2\lvert\theta\rvert)\). On the Einstein circle, exactly where \(\kappa = 1/2\), the critical curve sits. Mode kappa renders this mass map with the \(\kappa = 1/2\) critical curve highlighted in red.

The SIS Einstein radius depends directly on the galaxy's velocity dispersion \(\sigma_v\):

SIS Einstein radius
\[ \theta_E = 4\pi\left(\frac{\sigma_v}{c}\right)^2\frac{D_{ls}}{D_s} \]

Because \(\theta_E \propto \sigma_v^2\), changing the velocity dispersion rescales the entire mass map while keeping the core relationship (\(\kappa = 1/2\) at the critical curve) intact:

  • Default velocity dispersion (\(\sigma_v = 300\,\mathrm{km\,s^{-1}}\)): Yields a larger Einstein radius (\(\theta_E \approx 1.30''\)).
    python main.py --mode kappa --sigma_v 300
  • Lower dispersion (\(\sigma_v = 180\,\mathrm{km\,s^{-1}}\)): Scales the Einstein radius down (\(\theta_E \approx 0.47''\)).
    python main.py --mode kappa --sigma_v 180

Implementation Note: Enter \(\sigma_v\) in \(\mathrm{km\,s^{-1}}\); the program automatically converts it to \(\mathrm{m\,s^{-1}}\) internally so that \(\sigma_v\) and the speed of light \(c\) use consistent SI units.

Suggested Experiments

Nothing here needs anything beyond the program itself, its saved provenance sidecars, a ruler held up to the screen, and occasionally a pocket calculator. There is no fitting, no calibration and no convergence study to run, because nothing in this program is integrated or fitted in the first place; the numerical judgement these exercises ask for is about reading the figures and their provenance correctly.

Introductory

EXP-1

Two Panels, One Kink

Run --mode rays. In one sentence for each panel, say what changed about the observer's rays between the on-axis and off-axis cases, being careful not to describe it as something that changed about the lens.

EXP-2

Two, Always

Keep --beta_x 0.5 and run --mode point at three different --beta_y values, including zero. For each use the total source offset \(\beta=\sqrt{\beta_x^2+\beta_y^2}\), then compute \(\theta_\pm=\tfrac12(\beta\pm\sqrt{\beta^2+4\theta_E^2})\). Add --outdir ./figures to each run so it saves a matching .provenance.txt beside the PNG. Compare these signed distances along the source-lens line with the sidecar values; they are not generally the horizontal coordinate \(\theta_x\). Explain why a nonzero source offset gives exactly two point-source images.

EXP-3

A Ring Has No Preferred Direction

Run --mode blob --beta_x 0 --beta_y 0, then --mode blob --beta_y 0.8 --r_eff 0.20. Describe in words what "the caustic is a single point" implies about the first image, and what it implies about how abruptly the ring breaks into two arcs as the source moves off that point by even a small amount.

EXP-4

Two Planes, Never Confused

Run --mode critical. Point to the critical curve and say which plane it lives in; point to the caustic and say which plane it lives in. Then explain why an observer can point a telescope at the first but never directly at the second.

Intermediate

EXP-5

Crossing the Diamond

Reproduce Beat 5's four shear commands and record the image count each time. Then find, by trial, a fifth source position that crosses from 2 images to 4 by moving only --beta_y at fixed --beta_x 0.4, and identify which boundary (fold or pseudo-caustic) you crossed.

EXP-6

An Arc Is a Local Measurement

Compare --mode arcs --beta_x 0.18 --beta_y 0.30 --r_eff 0.14 (a source straddling a diagonal fold) with --mode arcs --beta_x 0.55 --r_eff 0.14 (a source straddling the short-axis cusp at \(\beta_x\approx0.519\) arcsec). Describe the bright arcs you can actually see, and explain why a fold creates a nearby image pair whereas a cusp crowds three images. A finite Gaussian may merge that group into one patch at this grid resolution; use the Beat 5 caustic panel to locate each boundary.

EXP-7

Convergence at the Ring

Run --mode kappa at two different --sigma_v values and confirm the Einstein radius scales as \(\sigma_v^2\), using the closed-form SIS formula. Then explain, from \(\kappa=\theta_E/(2|\theta|)\), why \(\kappa=1/2\) at \(|\theta|=\theta_E\) for any value of \(\sigma_v\) — the coincidence that kappa mode exists to make visible.

EXP-8

Magnification Adds Up

Run python main.py --mode point --outdir ./figures and read the signed ideal magnifications from its saved .provenance.txt file: +2.564097 and −1.564097. Repeat with python main.py --mode point --beta_x 1.0 --beta_y 0 --outdir ./figures: +1.599603 and −0.599603. In each run, confirm \(\mu_++\mu_-=|\mu_+|-|\mu_-|=1\). The algebra can be checked without a hidden trick: put \(u=\beta/\theta_E>0\); substituting the Beat 1 image radii into \(\mu=1/[1-(\theta_E/|\theta|)^4]\) gives \(\mu_\pm=\tfrac12\pm(u^2+2)/(2u\sqrt{u^2+4})\). Add the two expressions and show which terms cancel. This identity is not asserted for every circular lens profile.

Advanced

EXP-9

The Pseudo-Caustic Is Not the Caustic

Using --mode shear, place the source just inside the pseudo-caustic circle but well outside the diamond (2 images), then just inside the diamond near a fold (4 images), and read the image-plane panel each time for where the extra pair of images appeared. Explain why the image count changes at two different boundaries for this singular mass model, and what physically distinguishes "falling into the singularity" from "crossing a fold" as ways for an image to appear or disappear.

EXP-10

Where the Formula in Beat 5 Comes From

Beat 5 states the cusp locations at \(|\beta|=\tfrac23\theta_E\) on the \(\beta_y\)-axis and the fold's closest approach near \(0.275\,\theta_E\) on the diagonals, for the default \(\gamma=0.25\). Using the closed-form critical radius \(r(\phi)=\theta_E(1-\gamma\cos2\phi)/(1-\gamma^2)\) and the SIS+shear lens equation, reproduce those two numbers by evaluating the critical curve at \(\phi=90^\circ\) and \(\phi=45^\circ\) and pushing each point through the lens equation by hand. Then predict, before running it, whether the cusps move closer to or farther from the origin as \(\gamma\to1/3^-\), and check your prediction against --gamma 0.30.

Synthesis

EXP-11 · synthesis

One Equation, Seven Pictures

Make a table with one row per mode, giving the deflection law it uses, the beat that earns that law, and the one sentence that mode exists to demonstrate (a symmetry, a boundary, a count, a coincidence). Then write, in no more than four sentences, what changed about the physics between Beat 4 (a point mass) and Beat 5 (SIS plus shear) — not what changed about the picture, but what property of the mass distribution is responsible for the image count becoming a genuine function of source position instead of a constant.

Output

Each mode opens a Matplotlib window unless MPLBACKEND=Agg is set. With --outdir the program also writes a timestamped PNG and a same-stem .provenance.txt recording the mode, the version, and the build identifier. The figure footer repeats those two numbers so a saved plot can be matched to the Help file.

Domain of Validity

  • Thin lens, small angles. Fine for galaxy-scale strong lensing at arcsecond Einstein radii. Not a black-hole ray tracer.
  • Fixed distances 1 Gpc and 2 Gpc, chosen so \(\theta_E\) is a few arcseconds. They are not a cosmology. Angular-diameter distances are not generally related by \(D_{ls}=D_s-D_l\).
  • SIS + shear is the "cheapest" (i.e. requiring minimal computational and analytical effort) diamond, not an elliptical mass that has been fitted to a cluster. The dashed circle on the source plane is the SIS pseudo-caustic.
  • The Newton image finder is tested in the one-, two-, and four-image regions used by the Help file. If the source-plane distance to the nearest fold or cusp is less than \(10^{-4}\,\theta_E\), the count is not a promised teaching output.
