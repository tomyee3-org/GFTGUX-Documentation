Description

GravitationalLensing is a proposed new program for a second edition of Gravity from the Ground Up. It teaches the thin-lens mapping that turns a background galaxy into an Einstein ring, a double image, a quad, or a pair of arcs. Each section below is one beat: a short argument, the equation that argument earns, and a command whose window is the figure for that beat.

The spine of the lesson is one sentence: where the source sits relative to the caustic and the SIS pseudo-caustic decides the photograph. A point-mass lens is the chapter in which the caustic has collapsed to a point. An SIS plus a little external shear is the chapter in which the caustic opens into a diamond with folds and cusps.

What this program is not. It does not integrate null geodesics in the Schwarzschild metric (that is PhotonOrbit). It does not fit a mass model to a Hubble image. The thin-lens deflection is applied in one plane. Galaxy-scale strong lensing is the intended domain; a black-hole silhouette is not.
False colour. Modes point, blob, critical, arcs, and kappa paint intensity or convergence with a colour map. Those colours are a display scale, not the spectrum of the source. Gravitational deflection is achromatic: a point-mass or SIS lens does not split light into rainbows the way a glass prism or the atmosphere can. A white galaxy stays white; the program has simply chosen a palette so a faint arc is visible on a screen.
Reading this page. Equations are rendered by MathJax from a public CDN. Without a network connection the raw \(\LaTeX\) remains visible as text. The program itself needs no internet access.

Before the first run

Unpack the program zip so you have a folder named GravitationalLensing that contains main.py. Open a terminal in that folder. You need Python 3.10 or newer with NumPy and Matplotlib. If you do not already have that environment, follow the project-wide GFTGU Python Setup Guide (the link is the documentation repository root so you can download the whole tree with the green Code button, without a GitHub account). Do not install packages into a system Python (PEP 668). Then:

python main.py --version
python main.py --mode rays

Every command on this page assumes that working directory. Even values of --n_pix are rounded up to the next odd number so a pixel sits on the optical axis.

How to read this page

Each numbered section below is one beat: a short argument, the equation it earns, and the command that lets you test the argument. Do them in order the first time. After that, any mode can be opened on its own.

Beat 0 · Rays, no jargon

A glass lens bends more toward the rim. A point-mass gravitational lens does the opposite: a ray that skims the mass is bent hard, a ray that passes far away is barely bent. The observer is not sitting at a camera-lens focus. The observer only sees those rays whose deflection happens to aim at Earth.

On axis, symmetry makes every azimuth equivalent. There is one radius at which the bend is exactly right. That locus is the Einstein ring. Off axis the symmetry breaks and two rays survive — one outside the ring, one inside, on opposite sides of the lens.

Play

Run python main.py --mode rays. Both panels trace rays forward from one source. The height at the lens is the impact angle \(\theta\); the kink is the point-mass deflection that makes \(y\) at the observer vanish if and only if the lens equation holds. Red rays satisfy that equation and reach the observer. Blue rays miss. Gravity only attracts: every kink is toward the mass. Distances in this panel are schematic (\(D_l = D_{ls} = 1\), \(D_s = 2\)), so the vertical axis is the angle in radians. A default \(10^{12}\,M_\odot\) lens has \(\theta_E \sim 10^{-5}\). There is no artwork inside the observer marker. The lower panel uses the signed value of --beta_y: positive is above the axis, negative below.

Beat 1 · Play with a point mass

Now the same geometry as a picture on the sky. The default source is already off-axis, so the first frame is two images, not a ring.

python main.py --mode point
python main.py --mode point --beta_x 0.0 --beta_y 0.0
python main.py --mode point --logM 12.5 --beta_x 0.3 --beta_y 0.3

Three tasks, in order. First rerun with --beta_x 0 --beta_y 0 and name what appears. Then move the source in the vertical direction with a new --beta_y (that is the height drawn in every side view) and watch the ring split into two images. Then raise --logM and watch the ring grow. There is nothing to drag; each run is one command.

Then write the Einstein radius and the lens equation. The commands above were already solving them.

Point-mass Einstein radius
\[ \theta_E = \sqrt{\frac{4GM}{c^2}\,\frac{D_{ls}}{D_l D_s}} \]
Lens equation
\[ \boldsymbol{\beta} = \boldsymbol{\theta} - \boldsymbol{\alpha}(\boldsymbol{\theta}), \qquad \boldsymbol{\alpha}(\boldsymbol{\theta}) = \theta_E^2\,\frac{\boldsymbol{\theta}}{\lvert\boldsymbol{\theta}\rvert^2} \]

A \(10^{12}\,M_\odot\) lens halfway to a source at 2 Gpc gives \(\theta_E \approx 2''\). Those distances are illustrative only; they are chosen so Einstein radii come out in arcseconds. They are not a cosmological model, and angular-diameter distances in the real universe are not in general related by \(D_{ls}=D_s-D_l\). \(G\) and \(c\) are SI; mass is entered as \(\log_{10}(M/M_\odot)\). Compact-source width is held fixed at \(0.08''\). If you raise --logM, the field of view grows with the ring so the circle is not clipped.

Beat 2 · Why two, and where they sit

For a source on the \(x\)-axis at angular distance \(\beta\) from the lens, the two image radii are

Analytic double
\[ \theta_\pm = \frac{1}{2}\left(\beta \pm \sqrt{\beta^2 + 4\theta_E^2}\right). \]

\(\theta_+\) lies outside the Einstein ring; \(\theta_-\) lies inside, on the opposite side of the lens, and is mirror-reversed. On axis both sit at \(\pm\theta_E\) and the ring is complete. The cyan dashed circle drawn on the point figure is that ring. The white cross is the unlensed source position — the thing --beta_x and --beta_y move.

Parity. The sign of \(\det A\) is the parity of the image. Positive parity keeps the source's orientation. Negative parity mirrors it. For a point mass the outer image is positive and the inner image is negative.

Beat 3 · An extended blob, still a point mass

Replace the star with a small elliptical Gaussian. The lens equation does not change. A centred galaxy becomes a thick ring. Shift it with --beta_y and the ring splits into two arcs — the same geometry as the lower panel of --mode rays, now drawn as a (false-colour) photograph of an extended source.

python main.py --mode blob
python main.py --mode blob --beta_x 0.0 --beta_y 0.0
python main.py --mode blob --beta_y 0.8 --r_eff 0.20

For a point-mass lens the source plane still has only one distinguished point: the origin. A source there becomes a ring. A source anywhere else becomes two images. The next beat gives that point its name.

Beat 4 · Name the critical curve — and look at the rays that make the caustic

The lens mapping sends each sky position \(\boldsymbol{\theta}\) to a source position \(\boldsymbol{\beta}(\boldsymbol{\theta})\). The Jacobian of that map is \(A = \partial\boldsymbol{\beta}/\partial\boldsymbol{\theta}\). The signed magnification is

Signed magnification
\[ \mu = \frac{1}{\det A}. \]

The sign of \(\mu\) is the image parity. The factor that multiplies observed flux or area is \(\lvert\mu\rvert\). Negative parity is a mirror, not negative brightness. \(\lvert\mu\rvert\to\infty\) is the ideal point-source limit of a smooth model; a finite source such as the blobs in this program has a finite observed magnification.

Where \(\det A = 0\), that stretch diverges for a point source. That set, drawn on the sky, is the critical curve. Push the same set through the lens equation into the source plane and you have the caustic. A caustic is not a physical structure in space. It is a curve in the source plane marking where the lens mapping changes its image multiplicity.

Two planes. The critical curve lives in the image plane (the sky). The caustic lives in the source plane. The lens equation maps one into the other; they are not the same curve.

For a point mass,

Point-mass Jacobian
\[ \det A = 1 - \left(\frac{\theta_E}{\lvert\theta\rvert}\right)^4. \]

The zero set is the Einstein circle. Mapped backwards it collapses to one point at \(\beta = 0\). On that point: a ring. Off it: two images. That is the whole point-mass zoo.

Mode critical shows three panels at once: the photograph with the critical curve overplotted; the source plane with the caustic marked as a star at the origin; and a side-view of the same source. The side view is the thin-lens unwrapping of Beat 0, not a Schwarzschild geodesic. Red rays reach the observer; blue rays miss. The height in that panel is \(\beta_y\). The diagram is a slice through a three-dimensional geometry. Motion in \(\beta_x\) points into or out of the page and cannot be shown in this projection — use --beta_y to move the star in the drawing.

python main.py --mode critical
python main.py --mode critical --beta_y 0.4
Leave the mass alone for this beat. Changing --logM only resizes a self-similar circle. The default mass is already in the figure. The coordinate that changes what you see is the source position, and on the side view that coordinate is --beta_y.

Beat 5 · Break the symmetry

A real lensing galaxy is not a point mass. The teaching model is a singular isothermal sphere plus a little external shear \(\gamma\):

SIS + shear deflection
\[ \boldsymbol{\alpha} = \theta_E\,\hat{\boldsymbol{\theta}} + (\gamma\,\theta_x,\,-\gamma\,\theta_y). \]

The critical curve opens into an oval on the sky. The caustic opens into a diamond in the source plane. The four sharp corners of the diamond are cusps. The four smooth sides are folds. Moving the source without crossing a caustic or the pseudo-caustic merely moves existing images.

Because the mass model is singular at the origin there is a second boundary, the pseudo-caustic: the image of that singularity, drawn as a dashed circle of radius \(\theta_E\) on the source plane. Outside it only one image remains: the missing image has merged with the central singularity. This disappearance is a consequence of the SIS singularity; a galaxy with a finite-density core behaves differently. Image number changes when the source crosses a true caustic or this singular-model pseudo-caustic.

The program admits only \(\lvert\gamma\rvert < 1/3\). That bound keeps the diamond inside the pseudo-caustic, so the table below has no three-image “naked cusp” region. The default \(\gamma=0.25\) is a little shear in that sense.

python main.py --mode shear --beta_x 0.55 --beta_y 0.10
python main.py --mode shear --beta_x 0.05 --beta_y 0.03
python main.py --mode shear --beta_x 2.0 --beta_y 0.0
python main.py --mode shear --gamma 0 --beta_x 0 --beta_y 0

Count the numbered dots on the left panel. The dashed circle is the pseudo-caustic. The last command is the Einstein-ring degeneracy.

Beat 6 · Arcs as a fat source on the same diamond

Keep the SIS + shear lens. Light up an extended ellipse instead of a star. Drape it on a fold and you get two long arcs. Drape it on a cusp and one arc splits. Park it at the origin with the default shear and you get four arcs around the oval critical curve — broken symmetry again, not a ring. A circular ring needs the shear removed.

python main.py --mode arcs
python main.py --mode arcs --beta_x 0.55 --r_eff 0.14
python main.py --mode arcs --beta_x 0.00 --beta_y 0.00 --r_eff 0.20
python main.py --mode arcs --gamma 0 --beta_x 0 --beta_y 0 --r_eff 0.20

Beat 7 · Only now: what \(\kappa\) is

Convergence is projected surface density in units of the critical density for lensing,

Convergence
\[ \kappa(\boldsymbol{\theta}) = \frac{\Sigma(\boldsymbol{\theta})}{\Sigma_{\mathrm{crit}}}. \]

For an SIS, \(\kappa = \theta_E/(2\lvert\theta\rvert)\). On the Einstein circle \(\kappa = 1/2\), and that is exactly where the critical curve sits. Mode kappa draws the mass map with that \(\kappa=1/2\) circle on top. Changing --sigma_v rescales the map; the relation “critical curve where \(\kappa=1/2\)” does not change. That is why this mode comes last: you already know what the circle is.

python main.py --mode kappa
python main.py --mode kappa --sigma_v 180

The SIS Einstein radius itself is

SIS Einstein radius
\[ \theta_E = 4\pi\left(\frac{\sigma_v}{c}\right)^2\frac{D_{ls}}{D_s}. \]

\(\sigma_v\) is entered in km/s and converted to m/s before use. A label of “km/s” with a raw value of 200 against \(c = 3\times 10^8\,\mathrm{m\,s^{-1}}\) is a thousandfold error; the program will not make it.

Module Overview

physics_gl.py
Engine

Einstein radii, both deflections, Jacobians, the analytic double, the SIS+shear critical curve and caustic, the Newton image finder, source profiles, and the thin-lens side-view rays.

plot_gl.py
Figures

One drawing routine per mode. Writes a timestamped PNG and a .provenance.txt sidecar when --outdir is set. Every figure carries the version and build in the footer.

driver_gl.py
Glue

Builds the grid, calls the engine, and hands arrays to the plotter. MPLBACKEND=Agg suppresses the on-screen window so tests can run headless.

main.py
CLI

Argparse entry point. --version prints GravitationalLensing VERSION (build BUILD_ID).

Output

Each mode opens a Matplotlib window unless MPLBACKEND=Agg is set. With --outdir the program also writes a timestamped PNG and a same-stem .provenance.txt recording the mode, the version, and the build identifier. The figure footer repeats those two numbers so a saved plot can be matched to the Help file.

Domain of Validity

  • Thin lens, small angles. Fine for galaxy-scale strong lensing at arcsecond Einstein radii. Not a black-hole ray tracer.
  • Fixed distances 1 Gpc and 2 Gpc, chosen so \(\theta_E\) is a few arcseconds. They are not a cosmology. Angular-diameter distances are not generally related by \(D_{ls}=D_s-D_l\).
  • SIS + shear is the cheapest diamond, not an elliptical mass that has been fitted to a cluster. The dashed circle on the source plane is the SIS pseudo-caustic.
  • The Newton image finder is tested in the one-, two-, and four-image regions used by the Help file. If the source-plane distance to the nearest fold or cusp is less than \(10^{-4}\,\theta_E\), the count is not a promised teaching output.
