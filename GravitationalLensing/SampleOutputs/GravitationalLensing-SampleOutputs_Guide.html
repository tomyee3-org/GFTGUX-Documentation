Purpose. These seven figures survey every teaching mode of GravitationalLensing. The program is a thin-lens classroom tool, not a survey-pipeline lens modeler. Modes 1–4 use a point-mass lens; modes 5–7 use an SIS plus a little external shear, restricted to |γ| < 1/3 so the diamond stays inside the SIS pseudo-caustic. Intensity maps are false colour (inferno or viridis): gravitational deflection is achromatic.

1. Forward rays: on-axis ring and off-axis double

python main.py --mode rays --beta_y 0.35 --outdir ./figures --dpi 140

Forward bundle only. Red rays reach the observer; blue rays miss; axes are gray. The observer sits on the right. There is no backward shooting from the telescope.

What it shows

  • On axis, every impact parameter that maps to the Einstein ring is bent onto the observer, so the photograph is a ring.
  • Off axis (source raised by +0.35″), two impact parameters still hit: a brighter outer image and a fainter inner image on the opposite side of the lens.
  • Deflection is toward the mass. A ray that appears to be “repelled” is a drawing error; this figure does not make that error.

Headline values

  • Point-mass log10(M/M☉) = 12, Dl = 1 Gpc, Ds = 2 Gpc (cartoon distances).
  • Einstein radius θE = 2.018″.
  • Off-axis source height βy = +0.35″ (the vertical displacement that changes the side view).
  • Geometry: Dl = Dls = 1, Ds = 2 in schematic units, so plotted height is angle × distance.

2. Point-mass photograph of a compact source

python main.py --mode point --beta_x 0.50 --outdir ./figures --dpi 140

False-colour intensity (inferno). The dashed circle is the Einstein ring. The white cross is the unlensed source position, not an image.

What it shows

  • A compact source 0.50″ off axis produces the classic double: a bright image outside the ring and a fainter image inside, on the opposite side of the lens.
  • Both images sit on the line through the source and the lens centre.
  • The grid (227 × 227 over 6″) keeps each image-plane width above the program’s 0.8-interval visibility floor.

Headline values

  • θE = 2.018″, β = (0.50″, 0.00″), compact-source σ = 0.080″.
  • Analytic image radii: θ+ = +2.283″, θ− = −1.783″.
  • Signed magnifications: μ+ = +2.564 (positive parity), μ− = −1.564 (negative parity).
  • Field 6.00″, npix = 227, spacing 0.0265″.

3. Extended source on a point-mass lens

python main.py --mode blob --outdir ./figures --dpi 140

Same lens as sample 2, now with an elliptical Gaussian source. Finite size turns the two compact images into two distorted patches; the ring itself is no longer a hairline.

What it shows

  • Source size and shape matter as well as position. A compact source gave two dots; an extended source gives two blobs whose long axes follow the local mapping.
  • The field grows if needed so the mapped half-light contour stays inside the frame. Here the default 6″ already contains it.

Headline values

  • θE = 2.018″, β = (0.15″, 0.05″).
  • Source: Re = 0.25″, q = 0.60, φ = 30°.
  • Field 6.00″, npix = 181.

4. Critical curve, caustic, and side-view rays

python main.py --mode critical --beta_y 0.35 --outdir ./figures --dpi 140

Left: image plane with the Einstein ring (critical curve) and the two images. Middle: source plane; for a point mass the caustic has collapsed to the origin. Right: the same forward bundle as sample 1, driven by βy.

What it shows

  • The critical curve is the locus of infinite magnification in the image plane (det A = 0). For a point mass that locus is the Einstein circle.
  • The caustic is the image of that curve in the source plane. For a point mass it is a single point at the origin. Sit the source there and the photograph is a ring; move it off and the ring splits.
  • The side view is a vertical slice. Shifting βx does not change that panel; shifting βy does.

Headline values

  • θE = 2.018″, β = (0.00″, 0.35″).
  • det A = 1 − (θE/|θ|)4 vanishes on |θ| = θE.
  • Field 6.00″, npix = 227, compact-source σ = 0.080″.

5. SIS + shear: diamond, folds, and cusps

python main.py --mode shear --gamma 0.25 --outdir ./figures --dpi 140

Left: image plane, analytic critical curve (solid) and SIS pseudo-caustic scale. Right: source plane, diamond caustic (folds and four cusps) inside the circular SIS pseudo-caustic (dashed). The source (cross) sits inside the diamond, so four images appear.

What it shows

  • A little external shear opens the point-mass caustic into a diamond. The sides are folds; the corners are cusps.
  • Inside the diamond: four images. Between the diamond and the pseudo-caustic: two images. Outside the pseudo-caustic: one image.
  • |γ| is kept below 1/3 so the cusps stay inside the pseudo-caustic. Naked cusps and a three-image region are outside the teaching domain.

Headline values

  • σv = 300 km s−1, θE = 1.298″, γ = +0.25.
  • Critical-curve radii: θE/(1+|γ|) = 1.038″ to θE/(1−|γ|) = 1.730″.
  • Diamond half-axis (cusp) = 2 θE |γ|/(1+|γ|) = 0.519″.
  • Source β = (0.05″, 0.03″) → four images.

6. Tangential arcs from an elliptical galaxy

python main.py --mode arcs --beta_x 0.18 --outdir ./figures --dpi 140

False-colour image plane with the analytic critical curve overplotted. An elliptical source near a fold is stretched into tangential arcs. Colour is intensity, not wavelength.

What it shows

  • A source that is merely near a fold, not on it, already produces long thin images because magnification is large along the fold.
  • The field uses the conservative bound (|β| + Re + θE)/(1−|γ|) so an off-axis source is not clipped. The Help default still fits in 6″; βx = 2″ would grow the field automatically.

Headline values

  • σv = 300 km s−1, θE = 1.298″, γ = 0.25.
  • Source: β = (0.18″, 0.00″), Re = 0.25″, q = 0.60, φ = 30°.
  • Field 6.00″, npix = 181.

7. SIS convergence and the κ = 1/2 circle

python main.py --mode kappa --outdir ./figures --dpi 140

Log-scaled false-colour κ map (viridis). The overplotted circle is κ = 1/2, which for an SIS is exactly the Einstein circle and the critical curve.

What it shows

  • For an SIS, κ(θ) = θE / (2|θ|). On |θ| = θE one has κ = 1/2, and that is where det A vanishes.
  • Changing σv rescales the map. The identity “critical curve where κ = 1/2” does not change.
  • A σv so small that θE spans fewer than four grid intervals is rejected, so the circle remains a visible feature.

Headline values

  • σv = 300 km s−1, θE = 1.298″.
  • κ = 1/2 on |θ| = 1.298″.
  • Field 6.00″, npix = 181.

Notes for evaluation

  • The seven modes are one tutorial sequence, not seven independent research codes. Rays explain the ring and the double; point and blob are the photographs; critical names the curve and the caustic; shear opens the caustic into a diamond; arcs is that diamond applied to an extended galaxy; kappa shows why the Einstein circle is special for an SIS.
  • External shear is restricted to |γ| < 1/3. Naked cusps and a three-image region are excluded on purpose.
  • Image counts within 10−4 θE of a fold or cusp are not a promised teaching output.
  • Intensity maps are false colour. Gravitational deflection does not split starlight into a spectrum.
  • --outdir PATH writes a timestamped PNG and a same-stem provenance text file.
  • Distances are a fixed 1 Gpc / 2 Gpc cartoon. Changing cosmology is not an exercise in this program.
