Before the first run

Use Python 3.10 or later with NumPy and Matplotlib. In the directory containing main.py, run python main.py --version and compare it with the version/build at the top of this page. Each beat command opens a Matplotlib figure; --outdir ./figures also saves a PNG. --csvdir ./data writes a timestamped CSV containing metadata and the columns t_s,f_hz,A,h,phase_rad. The default 1.4+1.4 solar-mass run exports roughly 789,000 rows; for small CSV experiments begin at --f_start 100 instead. Use python main.py --help to inspect all parameters.

Reading the panels: The top panel is the strain h(t); the middle panel is its inspiral amplitude scale A(t); the bottom panel is the gravitational-wave frequency f(t). A full 158-second plot cannot resolve individual late-time cycles at ordinary screen width; use Matplotlib's zoom or the --t_before window to inspect them. The lower-right Matplotlib toolbar shows cursor coordinates in the current axes.

Beat 0 · See two changes at once

Which panel tells you the cycles accelerate, and which one tells you the strain scale grows?

python main.py --outdir ./figures

Read the printout: Mc=1.2188 M☉, 157.868 s from 20 Hz to f_ISCO=1570.4 Hz, and a face-on amplitude scale of 5.583e-23 at cutoff. The full 158-second trace packs too many cycles into one screen width; zoom the last few hundredths of a second to see individual oscillations. The middle panel is an envelope, not a separate detector signal.

DERIVED After the run, attach the equation: df/dt=(96/5)π^(8/3)(G Mc/c³)^(5/3) f^(11/3), where Mc=(m1 m2)^(3/5)/(m1+m2)^(1/5). The strain scale A=4(G Mc)^(5/3)(πf)^(2/3)/(c⁴d) grows with frequency and falls as 1/d.

Beat 1 · Change the masses, keep the questions

Make a heavier binary. Before looking at the summary, predict the direction of the change in its time in band and cutoff frequency.

python main.py --m1 36 --m2 29 --d 440 --outdir ./figures

This pair takes 0.813 s to sweep from 20 Hz to 67.6 Hz; its Mc=28.0956 M☉. The ISCO strain scale is 1.165e-21 at 440 Mpc. Compare the masses, distance and cutoff with Beat 0. Both chirp mass and total mass have changed: do not attribute every difference to one knob.

DERIVED f_ISCO=c³/[6^(3/2)πG(m1+m2)] depends on total mass; the frequency sweep depends on chirp mass. To isolate either, choose a controlled comparison in the experiments.

Beat 2 · Watch the model change at the dotted line

What ends at ISCO, and what begins only because we request it?

python main.py --m1 36 --m2 29 --d 440 --ringdown --t_before 0.2 --t_after 0.05 --outdir ./figures

Read f_QNM=195.5 Hz and τ=3.417 ms for an assumed 61.750 M☉ nonspinning remnant. The red damped signal joins the blue strain continuously; the frequency and inspiral envelope panels stop at the cutoff. The figure labels the extension “illustrative ringdown — not a physical merger.” The calculated signal does not cross a modeled merger regime.

PRESCRIPTION M_final=0.95(m1+m2) and zero spin are teaching choices. The Schwarzschild mode (G M_final/c³)ω≈0.3737−0.0890i gives f_QNM∝1/M_final and τ∝M_final, conditional on that choice.

Try it yourself · one question per run

  1. python main.py --d 200 — what happens to the ISCO strain scale, and what stays fixed?
  2. python main.py --f_start 40 — how much of the 157.868-second default run did the 20–40 Hz segment account for?
  3. python main.py --m1 20 --m2 20 --f_start 40 followed by python main.py --m1 30 --m2 10 --f_start 40 — which printed quantity stays fixed when total mass stays 40 M☉?
  4. python main.py --m1 36 --m2 29 --d 440 --dt 0.0001 — how much does the printed cutoff time shift? For numerical order, which fixed interior time should a CSV comparison use instead?
  5. python main.py --f_start 100 --csvdir ./data — use two adjacent t_s,f_hz rows to estimate df/dt; take their mean frequency as f_mid. Can you recover Mc≈1.2188 M☉ from physics_gw.chirp_mass_from_fdot(f_mid, fdot_est)/physics_gw.M_sun? The function itself returns kilograms; divide by M_sun to report solar masses.
  6. python main.py --m1 20 --m2 20 --ringdown --f_start 40 then python main.py --m1 40 --m2 40 --ringdown --f_start 40 — what happens to the QNM frequency and decay time?
  7. Revisit Beat 2 — which plotted traces stop at ISCO, and which one continues as a prescribed toy signal?

Quick reference after the three runs

--m1, --m2 and --d set masses and distance; --f_start and --dt set the band entrance and numerical step. --ringdown adds a Schwarzschild QNM with --n_tau decay times and --rd_pts points: at least eight samples per QNM cycle are required. --t_before/--t_after zoom the display only. --outdir saves a PNG; --csvdir saves the waveform columns t_s,f_hz,A,h,phase_rad with run metadata; --lw adjusts plotted line width and --dpi accepts 1 through 600. See python main.py --help for defaults and full bounds.

CSV and PNG publication is complete per individual file in a trusted output directory with hard-link support; two requested outputs are not one transaction. Keep an untrusted co-tenant out of that directory. Diagnostics go to standard error. An interrupted export can leave a .gw_tmp_* private file or an empty .gw_modeprobe_* permission probe, for PNG as well as CSV; after the process stops, either can be removed. The build hashes the four core sources after CRLF/LF newline normalization, so document edits do not change it.

What the figure cannot represent

This is leading-order quasi-circular inspiral ending at a Schwarzschild ISCO cutoff. Its A is a face-on strain scale, not a detector response. Spin, eccentricity, inclination, cosmological redshift, tides, higher harmonics and the merger itself are absent. The optional zero-spin ringdown is illustrative only. The final-step cutoff time uses linear interpolation; use interior samples for a clean RK4 convergence check. Source calculations use GM_sun_nominal=1.3271244e20 m³/s² with the internally derived, unrounded M_sun=GM_sun_nominal/G.
