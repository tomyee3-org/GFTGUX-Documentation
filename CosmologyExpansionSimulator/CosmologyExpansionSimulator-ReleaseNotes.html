Major Improvements in This Release

  • 1.6.1: constant-w Big Rip figures continue the full Friedmann model toward its finite-time limit after the requested scale-factor bound, with a dashed display curve and limit marker. CSV data remain bounded by the requested run; an explicit time bound suppresses the display continuation.
  • 1.6.2: evolve summaries print computed ages, turnaround scale factors/times, total lifetimes and past-eternal elapsed times to 17 significant figures. Integration results are unchanged; additional digits expose numerical precision, not a claim of physical accuracy.
  • 1.6.2: classified evolve models have a separate Model fate line; comparison age charts distinguish past-eternal models from runs that did not reach the present epoch.
  • Tests accommodate the single merged Help's three Beats and six worked commands. The Guide uses current examples in Beat order, with a supplementary Big Rip figure illustrating the new display.

Test Suite Growth

1.6.0: 98 tests. 1.6.1: 102 tests, including four Big Rip plotting regressions. 1.6.2: 106 tests, including four new console/chart regressions and revised existing Help/Guide checks. All 106 pass under python -m unittest discover -s tests -q with the sibling documentation folder present. All six worked commands also execute successfully. Program-only checkouts skip the six documentation checks when Help is absent.

Known Limitations

FLRW background calculation only; no perturbations or physical dark-energy theory. CPL extrapolation and Big Rip estimates are conditional model calculations; finite precision, finite crossing searches and the age scan's finite a=5 recollapse horizon apply.

Known Minor Maintenance Items

Existing extreme-parameter tests can emit NumPy RuntimeWarnings. The draft Help still needs the author edits and proofreading detailed in the accompanying response, including conservation assumptions, exercise phrasing and observational qualifications.

Major Improvements in This Release

Known Limitations

  • FLRW perfect-fluid background only; no density perturbations, galaxy formation, or dark-energy microphysics.
  • The CPL equation of state is a phenomenological ansatz and its far-future extrapolation is not a physical prediction.

Known Minor Maintenance Items

  • Some extreme-parameter pathways can emit NumPy RuntimeWarnings even when the final input rejection or classification is correct. The current documentation and test work does not change this numerical policy; investigate with a captured reproducer in a later code round.
  • Claude Audit41 suggested an optional defensive guard for an empty finite-H array in the plotting tick calculation; the reviewed integration path cannot produce an identically zero H trajectory.
