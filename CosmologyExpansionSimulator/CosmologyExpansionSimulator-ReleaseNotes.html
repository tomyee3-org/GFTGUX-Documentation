Release Status

Claude Audit41 independently reviewed the Kickoff4 candidate and recommends APPROVE. The prior 1.5.0 numerical release had independent Audit 7–9 review; Claude verified both current tutorial styles, the 1.6.0 plotting adjustment, all four regenerated sample figures, and the complete 98-test suite.

Open Bugs

Claude Audit41 found no P1–P3 defects. No such defects are open in this approved candidate.

Major Improvements in This Release

  • Preserved the previous Reference Guide byte-for-byte as CosmologyExpansionSimulator-original.html, separate from both new tutorial Helps.
  • Added Claude-style worked-laboratory and Grok-style terminal-script Helps. They share the same four source modules, version 1.6.0, build 775b2b0ceb21, and commands for four figure beats.
  • Regenerated four embedded figures from this build, reordered the SampleOutputs Guide by beat, replaced inherited images and historical provenance, and synchronized captions and printed numerical checkpoints.
  • Clarified the finite a=5 recollapse horizon of age scans, the exact-flatness default, the physical age of past-eternal models, and the distinction between a displayed bound and an eventual fate.
  • Made the signed Hubble-axis tick labels legible around turnaround in contracting-branch figures; this visible plotting change bumps the minor model version to 1.6.0.

Test Suite Growth

Previous build: 91 physics and integration tests, all passed under python -m unittest tests.test_physics_cosmo -q. Kickoff4: 98 tests (91 existing plus 6 paired-help/guide contract tests and one contracting-axis readability regression), all passing under the same command with both current Helps under the sibling Documentation repository. Program-only layouts skip the document checks when neither Help is present; a layout with only one current Help fails those checks.

Known Limitations

  • FLRW perfect-fluid background only; no density perturbations, galaxy formation, or dark-energy microphysics.
  • The CPL equation of state is a phenomenological ansatz and its far-future extrapolation is not a physical prediction.
  • Age-scan recollapse flags search only through a=5; arbitrarily close epoch crossings may escape finite numerical scans. Integration and root finding have finite precision and bounds.

Known Minor Maintenance Items

  • Some extreme-parameter pathways can emit NumPy RuntimeWarnings even when the final input rejection or classification is correct. The current documentation and test work does not change this numerical policy; investigate with a captured reproducer in a later code round.
  • Claude Audit41 suggested an optional defensive guard for an empty finite-H array in the plotting tick calculation; the reviewed integration path cannot produce an identically zero H trajectory.
