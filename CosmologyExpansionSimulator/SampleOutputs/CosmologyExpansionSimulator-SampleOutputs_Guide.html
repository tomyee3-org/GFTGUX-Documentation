Beat 0 — A flat model from radiation to dark energy

Exact command:

python main.py --mode evolve --H0 67.4 --omega_m 0.315 --outdir ./figures

What it shows

  • The scale factor grows from the early model through a=1 and into the future.
  • Radiation, matter and dark energy exchange dominance; the dotted budget sum is unity where defined.
  • The Hubble parameter decreases, while q changes sign as acceleration begins.

Headline values

  • Age at a=1: 13.79 Gyr; Hubble time: 14.5073 Gyr.
  • Ωk0 = 0 by closure; ΩDE0 = 0.68491.
  • Matter–radiation equality: z = 3408; acceleration transition: z = 0.6317.
  • Matter–dark-energy equality: z = 0.2955; q0 = −0.5273.

Beat 1 — The age crisis as a parameter scan

Exact command:

python main.py --mode age --scan_param omega_m --scan_lo 0.05 --scan_hi 1.5 --scan_n 50 --outdir ./figures

What it shows

  • The 13 Gyr line is an evaluation reference, not a fitted measurement.
  • The dimensionless panel plots H0 t0 against matter density.
  • Recollapse markers record a search only to a=5; they do not classify all later times.

Headline values

  • Scan: Ωm0 = 0.05 to 1.5, 50 points, H0 = 70 km/s/Mpc.
  • Oldest point: 20.75 Gyr at Ωm0 = 0.05.
  • Youngest point: 8.105 Gyr at Ωm0 = 1.5.
  • 17/50 points reach a=1 and subsequently recollapse within a≤5.

Beat 2 — Four teaching cosmologies compared

Exact command:

python main.py --mode compare --presets EdS,lambdaCDM,closed,phantom --outdir ./figures

What it shows

  • Each curve marks its own present epoch a=1.
  • The histories and deceleration panels separate matter-only and dark-energy behavior.
  • The fate table distinguishes an eventual Big Rip from a recollapse.

Headline values

  • EdS age: 9.312 Gyr; H0 t0 = 0.6667.
  • Flat lambdaCDM age: 13.79 Gyr; acceleration z = 0.6317.
  • Closed age: 8.538 Gyr; note: recollapses.
  • Phantom age: 14.15 Gyr; note: Big Rip ahead.

Beat 3 — A closed model expands and contracts

Exact command:

python main.py --mode evolve --omega_m 1.5 --omega_de 0.0 --continue_collapse --outdir ./figures

What it shows

  • The expansion reaches a maximum scale factor before reversing.
  • H changes sign between the expanding and contracting branches.
  • At turnaround q and fractional densities are undefined; the branch ends at a_i.

Headline values

  • Ωm0 = 1.5, ΩDE0 = 0, Ωk0 = −0.50009.
  • Age at a=1: 8.538 Gyr.
  • Turnaround: a = 2.9995 at t = 93.06 Gyr.
  • Estimated Big-Bang-to-Big-Crunch lifetime: 186.1 Gyr.

Notes for evaluation

  • Run the exact command above from the directory containing main.py; the terminal produces the numerical values and stopping condition.
  • Use the lower-right Matplotlib cursor coordinate readout for a plot estimate, taking the current axis scales into account.
  • The age scan's recollapse test stops at a=5; an unmarked model is not certified as expanding forever.
  • --csvdir ./data saves numerical output; use --no_plot --csvdir ./data for data-only runs.
