Beat 1 — Five preset cosmologies

Exact command:

What it shows

  • Each present-age marker refers to that model’s a = 1 epoch.
  • The age bars rank these five finite-age models; other supported models can instead have labeled unavailable ages.
  • The preset names select complete parameter sets, so their Hubble constants need not all be identical.

Headline values

  • EdS: age 9.312 Gyr; H0 t0 = 0.6667; q0 = 0.5.
  • lambdaCDM: age 13.79 Gyr; H0 t0 = 0.9506; acceleration z = 0.6317.
  • Open: age 11.29 Gyr; closed: age 8.538 Gyr, with recollapse.
  • Phantom: age 14.15 Gyr; q0 = −0.733; Big Rip ahead.

Beat 2 — Historical age crisis

Exact command:

python main.py --mode age --scan_param omega_m --scan_lo 0.05 --scan_hi 1.5 --outdir ./figures

What it shows

  • Each scan point is made flat by default, with Omega_DE = 1 − Omega_m − Omega_r; --no_force_flat disables this.
  • The horizontal age reference is 13 Gyr; the inferred density depends on this chosen reference and H0.
  • The second panel removes the Hubble-time scale by plotting H0 t0.

Headline values

  • H0 = 70 km/s/Mpc; matter density scanned from 0.05 to 1.5 at 40 points.
  • Oldest sampled age: 20.75 Gyr at matter fraction 0.05.
  • Youngest sampled age: 8.105 Gyr at matter fraction 1.5.
  • The near-13-Gyr crossing is around matter fraction 0.34, between sampled rows.

Notes for evaluation

Headline values use this build's run output, rounded as indicated; the approximate crossing is read from the scan figure. The 17-digit evolve ages expose floating-point results, not corresponding physical accuracy. Preset compare output intentionally stays compact. A finite run endpoint does not determine a model's ultimate fate. The Big Rip display and the console DE-only estimate use different approximations.

Additional Beat 0 commands in the Help cover exact EdS and mirrored contraction; the EdS checkpoint is given above and the compare figure includes a recollapsing preset. The separate contracting example remains an interactive worked example.
