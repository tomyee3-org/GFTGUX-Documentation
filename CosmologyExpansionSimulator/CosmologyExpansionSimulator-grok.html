Plot tip: Hover your cursor over a graph in the Matplotlib window. Its (x, y) position in the graph’s coordinates appears in the lower right corner of the window.

Spine: A measured Hubble rate is not an age or a destiny. Give the Friedmann equation a content budget, then watch four different expansion histories emerge. Run each command before reading below it; use the terminal numbers as checkpoints rather than a plot legend.

Before the first run

Install NumPy and Matplotlib, open a terminal in the program folder and run python main.py --version. Check the version and build against the line above. Each command below displays a Matplotlib window; --outdir ./figures also saves a timestamped PNG. In an interactive window, the lower-right cursor readout gives the plotted coordinates under your pointer. Read axis labels and units before interpreting a slope. Run python main.py --help for all options. --csvdir ./data saves numerical data and metadata; --no_plot --csvdir ./data runs without a figure.

Three clocks: H0 has units km/s/Mpc, 1/H0 is a time scale, and age today is the computed time from a finite-age Big Bang to a=1. A past-eternal model has no finite Big-Bang age. Time on the plot is in Gyr; a=1 denotes today in each model.

Beat 0 · Start flat, then let the components trade places

Before running, predict which density will dominate at very small a and which will dominate far in the future.

python main.py --mode evolve --H0 67.4 --omega_m 0.315 --outdir ./figures

Read the age and both transition redshifts. Follow the radiation, matter and dark-energy fractions across the density panel. The printout says 13.79 Gyr and marks the deceleration-to-acceleration transition at z≈0.632; matter–dark-energy equality is later, z≈0.296. Which panel explains why these are different events?

ODE Now earn the equation: (H/H0)²=Ωm0/a³+Ωr0/a⁴+Ωk0/a²+ΩDE0 g(a). Here g(a)=1 for the default cosmological constant. The program sets Ωk0=0 when you omit --omega_de; explicitly supplying 0.685 gives Ωk0=-9.24e-5 because the small default radiation term still counts.

Beat 1 · An age scan is a conditional claim

Hold H0 fixed. How strongly can the composition change the time to reach a=1?

python main.py --mode age --scan_param omega_m --scan_lo 0.05 --scan_hi 1.5 --scan_n 50 --outdir ./figures

Read the endpoints in the summary: 20.75 and 8.105 Gyr for Ωm0=0.05 and 1.5. Locate the 13 Gyr reference line. The default scan adjusts dark energy to keep the models flat. Seventeen points are marked as recollapsing after reaching today, within the scan's look-ahead to a=5. An unmarked point has not been proved to expand forever.

DERIVED / NUMERICAL t0=∫₀¹ da/[a H0 E(a)] for a finite-age model. The numerical trajectory begins at a_i>0 with an analytic early-time offset. Its caption is a conditional calculation, not an independent measurement of the Universe's age.

Beat 2 · Four histories, one calculation

Compare the present-time marks and the printed age table. Which parameter set recollapses? Which has a future Big Rip?

python main.py --mode compare --presets EdS,lambdaCDM,closed,phantom --outdir ./figures

Keep the table alongside the figure: EdS 9.312 Gyr, lambdaCDM 13.79 Gyr, closed 8.538 Gyr and phantom 14.15 Gyr. The phantom note diagnoses an eventual fate; no plot here reaches infinite a. Each named preset supplies its own component budget.

DERIVED The acceleration relation is q=½Ωm+Ωr+½(1+3w)ΩDE. Curvature does not contribute a stress-energy term to this equation. Ask why similar Hubble rates can give different ages.

Beat 3 · Stop at a genuine turnaround

Trace the closed model up to its maximum a and back. Which sign of H belongs to each branch?

python main.py --mode evolve --omega_m 1.5 --omega_de 0.0 --continue_collapse --outdir ./figures

The summary reports a_turn≈2.9995, at 93.06 Gyr, and an estimated total lifetime of 186.1 Gyr. The contracting plot ends at a_i, not at the singularity. The q curve is undefined at turnaround where H=0.

ODE / SYMMETRY A true turnaround solves E(a)²=0. Reflecting the solution in time changes the sign of H. The doubling of turnaround time follows from the model's symmetry; the time itself is a numerical estimate.

Try it yourself · one question per run

  1. python main.py --mode evolve --omega_m 1 --omega_r 0 --omega_de 0 — compare the printed age to two thirds of the Hubble time.
  2. python main.py --mode age --scan_param omega_m --scan_lo 0.2 --scan_hi 1.2 --scan_n 20 --no_force_flat — which derived density now changes as you scan?
  3. python main.py --mode evolve --omega_m 1.5 --omega_de 0 --a_max 2 — does a plotting bound before the turnaround change the model's fate?
  4. python main.py --mode evolve --w0 -1.2 --a_max 60 — is a Big Rip on the plot, in the summary, or both?
  5. python main.py --mode evolve --omega_m 0 --omega_r 0 --omega_de 1 --a_i 0.01 — what appears in the physical age field for this past-eternal case?
  6. python main.py --mode evolve --H0 67.4 --omega_m 0.315 --step_frac 0.0025 — how much do the printed age and transition redshift move?
  7. python main.py --mode evolve --w0 -1 --wa 0.2 --a_max 2 — evaluate w(a)=w0+wa(1−a) at a=2. Is that formula a measured far-future law?

Quick reference after the four runs

evolve plots one history; compare overlays named presets; age scans one of omega_m, omega_de, w0 or H0. Use --outdir for PNGs and --csvdir for numerical output. --no_plot requires --csvdir. --step_frac controls a Hubble-time-scaled RK4 step and is not an error tolerance. --a_max and --t_max bound evolve and compare runs. --no_force_flat affects age scans only. See python main.py --help for valid options.

Where the model stops

The Friedmann equations describe an idealized homogeneous background. w(a)=w0+wa(1−a) is a phenomenological dark-energy fit, with density shape g(a)=a^[-3(1+w0+wa)] exp[-3wa(1−a)], not a measured future law. Fate classifications, early-time offsets and numerical ages have stated bounds; the age scan checks recollapse only through a=5. No plot includes galaxy structure, dark-energy microphysics or the quantum beginning of the Universe. A mathematical toy model need not describe the observed Universe.
