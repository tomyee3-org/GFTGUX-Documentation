Description

GravitationalWaveSources is a numerical investigation of the signal produced by a compact binary system as the two bodies spiral together. It follows a quasi-circular inspiral from a starting gravitational-wave frequency up to the innermost stable circular orbit, then appends a simple quasi-normal-mode ringdown.

The program's main purpose is visual: it lets a student see the chirp. The wave oscillations become closer together as the gravitational-wave frequency rises, while the strain amplitude grows until the merger region. The three plots show the waveform strain \(h(t)\), the amplitude envelope \(A(t)\), and the instantaneous gravitational-wave frequency \(f(t)\).

Ringdown visibility: the ringdown occurs on a very short time scale compared with the default full binary-neutron-star display. It will not be visible in an ordinary 150-second plot. To see it, zoom to the last fraction of a second and a few hundredths of a second after merger, for example with --t_before 0.05 --t_after 0.02.

Physical Background

What LIGO Measures

A passing gravitational wave changes the relative separation of freely falling test masses. The plotted waveform is a dimensionless strain, conventionally written \(h\). A value of \(h=10^{-21}\), for example, means a fractional length change of one part in \(10^{21}\). The simulator uses an averaged leading-order amplitude, so students should treat the plotted signal as a pedagogical waveform rather than a detector-specific matched-filter template.

Chirp Mass

The inspiral is controlled especially strongly by the chirp mass, the mass combination that appears in the leading frequency evolution:

Chirp mass
\[ \mathcal{M}=\frac{(m_1m_2)^{3/5}}{(m_1+m_2)^{1/5}}. \]

Increasing \(\mathcal{M}\) makes the chirp evolve faster in the detector band and raises the characteristic strain amplitude at a fixed distance.

ISCO and Ringdown

The inspiral portion stops at the Schwarzschild innermost stable circular orbit, abbreviated ISCO. After that point the code appends a damped sinusoidal quasi-normal-mode signal. This is a deliberately simple model of the final ringing of the remnant object.

Governing Equations

Frequency Sweep

The leading quadrupole-order evolution for the gravitational-wave frequency is

Peters quadrupole chirp
\[ \frac{df}{dt}=\frac{96}{5}\pi^{8/3}\left(\frac{G\mathcal{M}}{c^3}\right)^{5/3} f^{11/3}. \]

The exponent \(11/3\) is responsible for the accelerating chirp. As \(f\) rises, \(df/dt\) rises even more rapidly.

Strain Amplitude

The simulator uses a leading-order, sky-and-polarisation averaged amplitude:

Averaged strain amplitude
\[ A(f)=\frac{4G\mathcal{M}}{c^2d}\left(\frac{\pi G\mathcal{M}f}{c^3}\right)^{2/3}. \]

The amplitude scales inversely with luminosity distance \(d\), and grows with frequency during the inspiral.

ISCO Frequency

Schwarzschild ISCO
\[ f_{\rm ISCO}=\frac{c^3}{6^{3/2}\pi G M},\qquad M=m_1+m_2. \]

Larger total mass gives a lower ISCO frequency, so heavy black-hole binaries leave the inspiral band much sooner than neutron-star binaries.

Algorithm

  1. Read binary masses, distance, starting frequency, timestep, ringdown, zoom, plotting, and output options.
  2. Convert the input masses and distance to SI units.
  3. Compute \(\mathcal{M}\), total mass, the ISCO cutoff frequency, and approximate ringdown parameters.
  4. Integrate \(df/dt\) forward in time using the configured RK4 timestep until \(f_{\rm ISCO}\) is reached.
  5. Compute the amplitude envelope and waveform phase throughout the inspiral.
  6. Append a damped quasi-normal-mode ringdown after the merger time.
  7. Render the three-panel figure, either on screen or as a timestamped PNG.
  8. Print a summary table with masses, chirp mass, distance, band start, ISCO frequency, time in band, peak strain, final mass estimate, QNM frequency, and QNM decay time.
Numerical caution: decreasing --dt gives a smoother waveform and more samples, but costs more computation. Very heavy binaries or high starting frequencies may have short in-band times, so a coarse timestep can visibly undersample the last cycles.

Module Overview

Physics Layer
physics_gw.py

Defines constants, computes the chirp mass, evaluates the quadrupole frequency derivative, calculates the leading-order strain amplitude, supplies the Schwarzschild ISCO frequency, and integrates the inspiral plus ringdown.

def chirp_mass(m1_kg, m2_kg) def dfdt(f, Mc_kg) def strain_amplitude(f_hz, Mc_kg, d_m) def f_isco(M_total_kg) def integrate_inspiral(...)
Driver Layer
driver_gw.py

Runs the full calculation pipeline, passes the result to the plotter, and prints a compact run summary for the student.

def run(m1_msun=1.4, m2_msun=1.4, d_mpc=400.0, dt=1e-4, f_start=10.0, ...)
Plot Layer
plot_gw.py

Produces the three-panel Matplotlib display: waveform strain, amplitude envelope, and instantaneous gravitational-wave frequency. When requested, it saves a timestamped PNG.

def plot_inspiral(result, outdir=None, t_before=None, t_after=None, lw=0.4, dpi=150, figsize=(12, 9))
Entry Point
main.py

Defines command-line arguments for binary parameters, integration, zooming, plot style, and output. Run this file from the command line to perform an experiment.

python main.py python main.py --m1 36 --m2 29 --d 440 python main.py --t_before 0.05 --t_after 0.02

Output and Plot Panels

OutputWhat to Look For
Waveform h(t)Oscillations grow in amplitude and become more closely spaced as the binary approaches merger. In a long default plot the early oscillations may look like a dense band.
Envelope A(t)The envelope rises during inspiral. Compare runs at different distances to verify inverse-distance scaling.
Frequency f(t)The curve sweeps upward. More massive systems reach lower ISCO frequencies and spend less time in band.
Summary tableRecords the numerical outputs needed for a lab notebook: chirp mass, time in band, ISCO frequency, peak strain, QNM frequency, and decay time.
PNG fileIf --outdir PATH is supplied, the figure is saved in that folder with a timestamped filename.

python main.py

Suggested Experiments

EXP-1

Default Binary Neutron Star Chirp

Run python main.py. Record the time in band, chirp mass, ISCO frequency, and peak strain from the summary table. In the top panel, identify how the waveform spacing changes as merger approaches.

EXP-2

Make the Ringdown Visible

Run python main.py --t_before 0.05 --t_after 0.02 --lw 0.5. Compare with the default plot. The ringdown should be discussed only on this zoomed view, not on the full 150-second display.

EXP-3

Distance Scaling of Strain

Run the same masses with --d 100, --d 200, --d 400, and --d 800. Record the peak strain and test whether doubling the distance approximately halves the strain.

EXP-4

Chirp Mass Controls the Sweep

Compare --m1 1.4 --m2 1.4, --m1 10 --m2 10, and --m1 36 --m2 29. Record the chirp mass and time in band. Heavier systems should chirp in a shorter time from the same starting frequency.

EXP-5

Unequal-Mass Binary

Keep the total mass roughly fixed but vary the mass ratio, for example compare --m1 20 --m2 20 with --m1 30 --m2 10. Note how the chirp mass, time in band, and peak strain change.

EXP-6

Starting Frequency and Detector Band

Try --f_start 10, --f_start 20, and --f_start 40. A higher starting frequency removes the early, slower part of the inspiral and shortens the displayed time in band.

EXP-7

Numerical Time Step

Try --dt 1e-3, --dt 1e-4, and --dt 5e-5 on a short zoom near merger. Look for changes in smoothness and in the printed summary values.

EXP-8

Ringdown Sampling

On a ringdown zoom, compare --rd_pts 500, --rd_pts 4000, and --rd_pts 10000. The purpose is not to change the physical model, but to see how plotting resolution affects a rapidly damped oscillation.

EXP-9

Line Width and Dense Waveforms

For the full default display, try --lw 0.2, --lw 0.4, and --lw 1.0. A thin line is often clearer when many oscillations are compressed into one panel.

EXP-10

Notebook Challenge: Infer Trends

Make a table with columns for masses, chirp mass, distance, starting frequency, time in band, ISCO frequency, and peak strain. Use the table to state which parameters mainly control duration, frequency cutoff, and amplitude.

Restoring Default Parameter Values

After experimenting, the easiest way to return to the default setup is to rerun python main.py with no command-line options.

  • Same session: rerun the command without optional arguments.
  • If source files were edited: use PyCharm undo or Local History to restore the edited file.
  • Full reset: re-download the ZIP from github.com/tomyee3-org/GFTGU-Programs and replace this program's folder with the fresh copy.
