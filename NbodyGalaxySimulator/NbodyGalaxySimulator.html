Before the first command

Use Python 3.10 or later with NumPy and Matplotlib. Run from the directory containing main.py. The program assumes you have already tried the project’s Multiple program. Each command displays a Matplotlib figure and saves a timestamped PNG and provenance sidecar in ./figures. python main.py --version reports the build above; python main.py --help lists the flags. The same four runs and current-build figures are in the SampleOutputs Guide.

Working question: How do softening, the choice of initial state, and close initial conditions change what you can infer from a plot?

Beat 0 · The quiet baseline

Run first, then read the cluster's final instantaneously-unbound count and the near-escape time series. Does a quiet default plot prove significant two-body relaxation?

python main.py --mode cluster --seed 7 --outdir ./figures

For seed 7 the half-mass radius changes only about 1.286 → 1.302 pc, and the final unbound count is zero. The default ε≈0.2471 pc softens hard encounters; this quiet run cannot certify a relaxation-driven evaporation rate. The printed count is instantaneous, never cumulative.

Beat 1 · Lower softening, watch the tail

What changes if you weaken softening and give the cluster a longer run?

python main.py --mode cluster --n_bodies 60 --softening_pc 0.0338 --steps_per_crossing 150 --n_relax 40 --seed 0 --outdir ./figures

Watch the 90%-mass radius, near-escape fraction, instantaneously unbound count, and energy drift. Seed 0 ends with one of 60 bodies instantaneously unbound, a 3.33% near-escape tail and about 0.33% maximum sampled energy drift. Those values belong to this seed and these settings; repeat several seeds before generalizing.

Beat 2 · A sphere collapses, overshoots, settles?

Before you inspect the plot, name two histories you need in addition to a single final Q≈1.

python main.py --mode galaxy --seed 3 --outdir ./figures

The half-mass radius falls from about 162.6 to a sampled 18.5 pc minimum near 55.6 Myr, then rebounds. The virial ratio peaks above one and later becomes quieter. This seed passes the program's dense-step late-window check, evidence consistent with a quasi-equilibrium remnant. The 90%-mass shell still expands: the check does not establish equilibrium for all outer material. Q=2T/|W_vir|, where W_vir is the softened force term, not the potential energy.

Beat 3 · Two nearby histories part company

Guess whether two individually well-integrated trajectories must stay close to each other.

python main.py --mode chaos --seed 1 --perturbation_seed 1 --outdir ./figures

The separation can climb roughly exponentially over one chosen window and saturate at the cluster scale. Compare the terminal fit slope, the number of fitted snapshots and the energy drift. Set both --seed and --perturbation_seed to reproduce this particular figure; the latter defaults to unseeded. The reported Lyapunov time is a finite-time heuristic, not a universal asymptotic value.

After the four runs · controlled questions

  1. Return to Beat 0: a final zero count is one snapshot, not a historical escape census. With --csvdir ./data, where in the time series can you check whether a body was ever instantaneously unbound?
  2. Repeat Beat 1 with --seed 1, --seed 2 and --seed 3, holding every other flag fixed. Do the final counts agree? This is a four-seed sample, not a universal evaporation fraction.
  3. Hold --n_bodies 60, --seed 0, and the Beat 1 duration/step fixed; vary only --softening_pc. Compare the near-escape tail and maximum sampled energy drift before assigning cause.
  4. For Beat 2, run python main.py --mode galaxy --seed 3 --virial_ratio_init 0.4 --outdir ./figures. A warm initial sphere does not automatically qualify for a cold-collapse verdict. Inspect the shape of Q(t) and the radius history.
  5. Rerun Beat 3 with both seeds unchanged but --relative_perturbation 1e-9. Does the finite-time fitted growth rate remain within run-to-run scatter? Never infer a formal Lyapunov exponent from one selected fit window.
  6. Choose a small cluster and compare --method direct with --method tree --theta 0.5, holding its seed, timestep and softening fixed. At --theta 0 the tree descends fully; do not promise a speedup at every N or distribution.
  7. For a resolution comparison across --n_bodies, pass one fixed --softening_pc explicitly: its default scales as 0.98 a N^-0.26. For each setting, use several seeds. Compare the shift between median outcomes with the larger within-setting range (maximum minus minimum). A shift comparable to scatter is inconclusive, not proof of convergence; a clearly larger shift shows resolution or softening sensitivity.

Governing Equations · after the observations

Derived Newtonian force with prescribed softening: aᵢ = −Σⱼ≠ᵢ Gmⱼ(rᵢ−rⱼ)/(|rᵢ−rⱼ|²+ε²)^(3/2). The Barnes–Hut monopole approximation replaces distant groups by their center of mass; θ controls opening. W_vir=Σ rᵢ·Fᵢ is the softened scalar-virial force term and generally differs from potential energy U. A leapfrog kick–drift–kick step advances the positions and velocities; reducing the timestep tests numerical accuracy, not whether the chosen physical model is complete.

Algorithm and quick reference

--mode selects cluster, galaxy or chaos. --n_bodies and --total_mass_msun set the particle system; --scale_radius_pc applies to cluster/chaos, --radius_pc to galaxy. --n_relax and --steps_per_crossing control cluster duration and step; --n_freefall, --steps_per_freefall, --virial_ratio_init serve galaxy; --n_cross, --relative_perturbation and --perturbation_seed serve chaos. --softening_pc, --theta, --method, --seed, --target_snapshots, --outdir, --csvdir, --no_plot, --dpi and --lw are described by python main.py --help. --no_plot requires --csvdir. A PNG saved with --outdir has a provenance sidecar; CSV files include version/build metadata.

The tree's usual O(N log N) advantage requires a reasonably distributed tree and nonzero opening angle. A degenerate distribution or θ=0 can approach O(N²). Direct summation is an accuracy comparator, not a guarantee of shorter runtime.

Domain of Validity

This is a pure-Python equal-mass, softened Newtonian particle model for teaching; there is no gas, radiation, external tide, cosmological expansion, individual timestep or tree quadrupole term. A cold-collapse classifier's positive result means a finite final window met its six numerical gates (including a rebound and a near-unity mean virial ratio); it does not prove full phase-space equilibrium. --target_snapshots changes stored output, not the dense per-integration-step settling check.

The finite-time chaos-fit significance gate was calibrated in this program's tested regime; do not extrapolate it to a certified asymptotic exponent. A saturating, logistic-like separation curve can still pass a selected-window growth fit under contrived conditions; inspect the entire curve, including its saturation. Extremely unphysical mixtures differing by hundreds of orders of magnitude can escape the numerical safeguards; ordinary solar-mass and parsec-scale experiments stay inside the intended regime. Default cluster softening inhibits close encounters, so it cannot by itself establish a physical evaporation timescale.
