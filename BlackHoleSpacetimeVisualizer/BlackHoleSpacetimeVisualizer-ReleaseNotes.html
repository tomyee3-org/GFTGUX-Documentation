BlackHoleSpacetimeVisualizer 1.4.0 Release Notes

Version: 1.4.0; Build: 100876a488a0; Date: 2026-09-27.

Release Status

Kickoff4 resumes the supplied 1.4.0 candidate following its earlier Codex, Copilot, Gemini and Claude review cycles. The four core Python files are unchanged; independent Claude review of the two new tutorial formats, shared tests and regenerated guide is pending. The supplied previous notes are retained below as history until a release decision.

Open Bugs

No unresolved reviewer-reported P1–P3 defect is documented in the supplied 1.4.0 notes. Kickoff4 awaits independent review.

Major Improvements in This Release

  • Renamed the former reference-format Help to BlackHoleSpacetimeVisualizer-original.html without changing its content. Added two self-contained four-beat tutorials, one with detailed answers and provenance and the other led by runs and observations.
  • Both current Help files use the same core program, suite and guide, show Version 1.4.0 Build 100876a488a0, and direct students to the real command-line modes.
  • Regenerated all four sample figures from this unchanged build and updated the self-contained guide's commands, captions, values and image provenance.
  • Aligned both tutorial pages and the sample guide with the established Help/documentation typography, parchment and rust palette, and navigation or figure-section layout. This presentation change does not alter the core version/build.

Test Suite Growth

The supplied 1.4.0 suite had 139 passing tests. Kickoff4 raises the suite to 148 passing tests, adding shared checks that require both current tutorial files, verify their version/build and representative commands against the live parser, check the exercises named in the program's terminal output, and validate the sample guide's commands and embedded figures. Run once from the program directory: MPLBACKEND=Agg python -W error::RuntimeWarning -m unittest discover -s tests -p test_physics_bh.py -q. The full suite passed on the Kickoff4 host.

Known Limitations

  • Embedding describes one spatial slice; the reflected branch is a diagram convention.
  • Tidal acceleration across a finite separation is a leading-order geodesic-deviation estimate; no material strength or clinical survival model is supplied.
  • The infall calculation stops outside the Schwarzschild coordinate singularity and assumes radial point-particle motion.
  • Vaidya accretion uses a prescribed nondecreasing mass function and ingoing null dust; no black-hole spin, realistic disk or evaporation is included.

Known Minor Maintenance Items

No outstanding P4 item is listed in the supplied notes. Independent review may identify one.

Black Hole Spacetime Visualizer 1.4.0 Release Notes

Version: 1.4.0 Build: 100876a488a0 Date: 2026-08-26

Release Status

Version 1.4.0 concludes a multi-round independent review process involving Codex, Copilot, Gemini, and Claude response cycles. Earlier audits identified issues involving event-horizon construction, numerical robustness, convergence claims, diagnostic design, finite-precision behavior, documentation accuracy, and regression coverage. These findings were systematically addressed through architectural changes, expanded validation, documentation revisions, and substantial test-suite growth.

Major Improvements Since 1.1.x

  • Replaced the primary event-horizon construction with backward integration from the exact post-accretion boundary condition.
  • Added explicit event-horizon integrity checks and physical-invariant enforcement.
  • Corrected interpretation of early-time event-horizon displacement as a physical property rather than a numerical truncation error.
  • Repaired infall startup conditions using cycloid-based initialization.
  • Migrated mass-dependent calculations to the IAU nominal solar mass parameter.
  • Added Gaussian-curvature outputs and curvature-based educational exercises.
  • Introduced translation-invariant Vaidya horizon integration using shifted coordinates.
  • Corrected horizon-diagnostic methodology to evaluate exact node-based curve differences rather than sampled approximations.
  • Improved handling of long-duration accretion scenarios and strengthened horizon postconditions.
  • Added support for arbitrary finite advanced-time origins.
  • Improved finite-value validation, overflow protection, and computational-domain enforcement.
  • Added collision-safe CSV and image output generation.
  • Expanded student-facing documentation and exercise accuracy.
  • Added BUILD_ID provenance support and improved release consistency.

Test Suite Growth

90 → 111 → 130 → 139 tests across the audit process.

Known Limitations

  • Intended for education and conceptual exploration rather than research-grade numerical relativity.
  • Extreme parameter combinations may encounter computational-domain limits.
  • Tidal-force calculations use linearized geodesic-deviation approximations across finite separations.
  • Models remain idealized and do not include rotating black holes.
