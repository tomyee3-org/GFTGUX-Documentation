Major Improvements in This Release

The former horizon r_crit names are removed; tidal survival-radius names retain their established meaning. Python callers using the old horizon dictionary keys must update them.
  • The horizon summary prints its starting radius with 17 significant figures. The numerical trajectory and all sampled array values are unchanged.
  • Embedding annotations and the legend no longer obscure the profile ends. Output filename mass tags use six significant figures, preserving small masses instead of labeling them 0.00Msun.
  • Tom corrected the console-label references, header links, parameter styling and other Help wording in the supplied pre-response. His 18 October revision removes the obsolete EXP-6 precision workaround and restores the statement that both the summary and tidal CSV report unreliable linearization. Further substantive Help changes remain Tom's responsibility.
  • The Release Notes follow the seven-section plain-HTML format. The Sample Outputs Guide follows the figure-section layout, corrects the tidal-panel description, and contains four newly generated indexed PNGs from this build.

  • Repaired infall startup conditions using cycloid-based initialization.

  • Added Gaussian-curvature outputs and curvature-based educational exercises.
  • Introduced translation-invariant Vaidya horizon integration using shifted coordinates.
  • Corrected horizon-diagnostic methodology to evaluate exact node-based curve differences rather than sampled approximations.
  • Improved handling of long-duration accretion scenarios and strengthened horizon postconditions.
  • Added support for arbitrary finite advanced-time origins.
  • Improved finite-value validation, overflow protection, and computational-domain enforcement.
  • Added collision-safe CSV and image output generation.
  • Expanded student-facing documentation and exercise accuracy.
  • Added BUILD_ID provenance support and improved release consistency.
