Description

BlackHoleShadow is a proposed new program for a second edition of Gravity from the Ground Up. It teaches the one fact that PhotonOrbit and GravitationalLensing together still leave on the table: the black-hole “silhouette” is an image-plane set of captured null geodesics. A student who can already classify one Schwarzschild photon from its impact parameter \(b\), and who has already mapped a thin-lens source plane onto an image plane, has never launched a bundle of those photons into a camera and asked which directions on the sky go dark.

The spine of the lesson is one sentence:

The silhouette a camera records is the set of image-plane directions whose Schwarzschild null geodesics are captured — a critical curve at \(b_{\mathrm{crit}}=3\sqrt{3}\,M\), not a thin-lens \(\boldsymbol{\alpha}(\boldsymbol{\theta})\), and not the coordinate circle \(r_s\).

What this program is not. It is not a Kerr movie, not an Event Horizon Telescope pipeline, and not a radiative-transfer disk code. It is not PhotonOrbit with a slider: PhotonOrbit’s object is one affine ray and its accumulated \(\Delta\phi\). It is not GravitationalLensing with \(M\) set to a black hole: the thin-lens kink \(\boldsymbol{\alpha}=\theta_E^2\boldsymbol{\theta}/\lvert\boldsymbol{\theta}\rvert^2\) cannot produce the critical null geodesic that rims the shadow. It is not RelativisticOrbit (timelike zoom-whirls stay there) and not GravitationalWaveSources (no strain, no chirp mass).
False colour. Mode image paints bolometric intensity \(I_{\mathrm{obs}}=\sum_m g(r_m)^4 I_{\mathrm{em}}(r_m)\) with a colour map. Those colours are a display scale, not the spectrum of the source. Gravitational deflection is achromatic. The calculation is face-on and optically thin; there is no inclination slider.
Reading this page. Equations are rendered by MathJax from a public CDN. Without a network connection the raw \(\LaTeX\) remains visible as text. The program itself needs no internet access.

Before the first run

Unpack the program zip so you have a folder named BlackHoleShadow that contains main.py. Open a terminal in that folder. You need Python 3.10 or newer with NumPy and Matplotlib. If you do not already have that environment, follow the project-wide GFTGU Python Setup Guide. Do not install packages into a system Python (PEP 668). Then:

python main.py --version
python main.py --mode rays

Every command on this page assumes that working directory. Even values of --n_pix are rounded up to the next odd number so a pixel sits on the optical axis. Lengths are in units of \(M=GM/c^2\); the teaching default is \(M=1\).

Beat 0 · Two rays, already known

PhotonOrbit has already classified a single Schwarzschild photon. This beat repeats that classification with the same first integral so the later camera grid is visibly the same physics, not a new metric.

Null first integral (E = 1, L = b)
\[ \left(\frac{dr}{d\lambda}\right)^2 = 1 - \left(1-\frac{2M}{r}\right)\frac{b^2}{r^2}, \qquad b_{\mathrm{crit}} = 3\sqrt{3}\,M. \]

Run python main.py --mode rays. The red curve at the default \(b=5\) hits \(r_s=2M\) and is reported captured. The blue curve at \(b=6\) turns at a periapsis outside the photon sphere and is reported escaped. The console \(\Delta\phi\) is accumulated azimuth to a finite stopping surface (the horizon, or twice the camera radius), exactly as in PhotonOrbit. It is not the asymptotic deflection angle \(\hat\alpha\). That distinction is Beat 5.

Beat 1 · A ray becomes a pixel

The new object is only the camera map \((b_x,b_y)\mapsto\{\text{captured},\ \text{escaped}\}\). Place the same two impact parameters on a coarse grid. One cell is dark, one is light. Nothing about the ODE has changed.

python main.py --mode pixels

Beat 2 · The geometric shadow

A dense grid of the same classifier is a geometric capture map: a dark disk whose rim sits at the critical curve \(b_{\mathrm{crit}}\approx 5.196\,M\), not at the horizon radius \(2M\). BlackHoleSpacetimeVisualizer draws \(r_s\) as a circle in an embedding or a horizon diagram; that circle is not what a camera records. Only \(b_{\mathrm{crit}}\) is drawn on this map.

python main.py --mode capture
python main.py --mode capture --fov 24 --n_pix 201

The program refuses a grid on which the shadow diameter spans fewer than eight pixels. That is a visibility floor, not an EHT resolution claim.

Beat 3 · High-winding overlay (not a photon ring)

Three names that students mix up, kept apart on purpose:

  • the photon sphere is the spacetime locus \(r=3M\);
  • the critical curve is the image-plane circle \(b=b_{\mathrm{crit}}\);
  • a photon ring is a bright image that appears near that curve only when emitting matter sends high-order rays to the observer.

Mode ring does not compute a photon ring. It paints a pedagogical highlighter on escaping rays whose periapsis sits near \(r=3M\) and whose asymptotic azimuth exceeds \(2\pi\). Those rays are PhotonOrbit’s near-critical whirling (PhotonOrbit’s EXP-8, not this program’s EXP-8), shown as a set of directions on the sky rather than as one trajectory. The orange band is that high-winding window, not a measurement of photon-ring brightness. The width of the highlighted band is chosen by educational thresholds and should not be interpreted as a measured width of a physical photon ring.

python main.py --mode ring

Beat 4 · Transfer functions \(r_m(b)\)

A face-on observer at infinity looks down on a thin equatorial emitting plane. Each impact parameter \(b\) labels a null geodesic in a meridian plane. That geodesic crosses the disk at orbital angles \(\pi/2\), \(3\pi/2\), \(5\pi/2\), \ldots The radii of those crossings are the transfer functions \(r_m(b)\).

\(r_1\) is the direct image. \(r_2\) is the lensing-ring crossing. \(r_3\) and later are photon-ring / subring crossings. Captured rays (\(b\le b_{\mathrm{crit}}\)) only travel inbound, but they can still cross the disk before the horizon.

python main.py --mode transfer

Beat 5 · A face-on optically thin image

Give the disk an emitted profile \(I_{\mathrm{em}}(r)\), a Gaussian annulus at \(r_{\mathrm{hot}}=6M\) by default. The observed bolometric intensity is the Gralla–Holz–Wald toy sum

Optically thin face-on image
\[ I_{\mathrm{obs}}(b)=\sum_m g(r_m)^4 I_{\mathrm{em}}(r_m),\qquad g(r)=\sqrt{1-2M/r}. \]

Mode image draws three panels: direct (\(m=1\)), plus lensing (\(m\le 2\)), plus photon-ring (\(m\ge 3\)). False colour is a display scale. There is no inclination: a correct inclined image needs three-dimensional camera/disk geometry, which is a later program.

python main.py --mode image
python main.py --mode image --r_hot 8

For an annulus at \(6M\), most of the light is in the direct ring near \(b\sim 7M\). The lensing contribution sits just outside \(b_{\mathrm{crit}}\). The photon-ring panel is faint because those crossings hug \(r\sim 3M\), where this particular \(I_{\mathrm{em}}\) is small. That is a property of the source, not a bug.

Beat 6 · Coordinate radii are not image-plane radii

Two panels. The left panel is a Schwarzschild coordinate-radius cross-section: \(r_s=2M\) and the photon sphere \(r_{\mathrm{ph}}=3M\). It is not a spacetime diagram. The right panel is the image plane: only the critical curve \(b_{\mathrm{crit}}\) is drawn on the capture map. A finite camera records an angular critical curve related to \(b_{\mathrm{crit}}\), not a ruler measurement of \(b\).

python main.py --mode radii

Beat 7 · The weak-field formula is the same ray, far away

For an escaping photon the asymptotic deflection is \(\hat\alpha=\Delta\phi_\infty-\pi\), computed from the standard \(u=1/r\) integral of the same first integral. At large \(b\)

Weak-field light deflection
\[ \hat\alpha = \frac{4GM}{c^2 b} = \frac{4M}{b}. \]

Run python main.py --mode weak. The two curves agree at large \(b/M\) and come apart as \(b\to b_{\mathrm{crit}}^+\). That divergence is strong deflection: it permits higher-order images when a source supplies photons. It is not itself a photon ring.

Beat 8 · Do not call these the same ring

GravitationalLensing’s Einstein ring and this hole’s critical curve are different objects. One is the thin-lens critical curve of a transparent mass. The other is the capture boundary of the vacuum Schwarzschild metric.

python main.py --mode compare
python main.py --mode compare --logM 12.5

The default comparison is a \(10^{12}M_\odot\) point-mass galaxy at the GravitationalLensing cartoon distances \(D_l=1\,\mathrm{Gpc}\), \(D_s=2\,\mathrm{Gpc}\). Its \(\theta_E\) is a couple of arcseconds. The physical Einstein radius at that lens, in units of the galaxy’s own \(GM/c^2\), is of order \(10^5\). The photon sphere is \(3M\); the image-plane critical curve is \(b_{\mathrm{crit}}\approx 5.196\,M\).

Experiments

EXP-1 · First run

Capture versus escape

Run --mode rays at the defaults, then again with --b_in 5.19 --b_out 5.21. Name the status of each ray from the console before you look at the figure.

EXP-2 · Beginner

A pixel is a direction

Run --mode pixels. Point to the dark cell and the light cell and say which PhotonOrbit experiment each one is.

EXP-3 · Beginner

The rim is not the horizon

Run --mode radii. The left panel is a coordinate-radius cross-section; the right panel is the image plane. Which circle on the right matches the dark disk, and why are \(r_s\) and \(r_{\mathrm{ph}}\) not drawn there?

EXP-4 · Intermediate

PhotonOrbit EXP-4 / EXP-7 on the sky

The shadow rim is the critical ray of PhotonOrbit EXP-4 / EXP-7. The highlighter of --mode ring is PhotonOrbit’s EXP-8 painted as pixels. Write that sentence in your own words, then run both programs side by side.

EXP-5 · Intermediate

Recover \(4M/b\)

From the weak console line, compute the relative error of \(4M/b\) at the largest sampled \(b\). Then argue why the error must grow as you walk the curve toward \(b_{\mathrm{crit}}\).

EXP-6 · Intermediate

Two rings, two meanings

Run --mode compare. Quote \(R_E/M\) for the galaxy and \(b_{\mathrm{crit}}/M\) for the hole. Invent a sentence that uses the word “ring” once only.

EXP-7 · Intermediate

Achromatic silhouette

Run --mode image. The palette is inferno. Write down what would change if the annulus emitted blue light instead of red. (The capture map would not.) Then compare the three panels and say which crossing lights each ring.

EXP-8 · Advanced

Finite camera

Rerun --mode rays with --r_cam 10 and then --r_cam 80. The capture threshold in conserved \(b\) does not move. What does move is the local angle on the camera sky. Explain using \(\sin\alpha = (b/r)\sqrt{1-2M/r}\).

EXP-9 · Advanced

Resolution contract

Try --mode capture --fov 80 --n_pix 11. Read the error. Then satisfy the contract without raising --n_pix above 81.

EXP-10 · Advanced

What inclination is allowed to mean

Run --mode transfer. At the \(b\) of the direct-image peak, read \(r_1\). Does it sit near \(r_{\mathrm{hot}}\)? At a \(b\) just above \(b_{\mathrm{crit}}\), how many crossings exist?

Output

Each mode opens a Matplotlib window unless MPLBACKEND=Agg is set. With --outdir the program also writes a timestamped PNG and a same-stem .provenance.txt recording the mode, the version, and the build identifier. The figure footer repeats those two numbers so a saved plot can be matched to this Help file. The console summary prints \(b_{\mathrm{crit}}\), statuses, and a one-line reminder of what the beat is for.

Domain of Validity

  • Schwarzschild only. Geometric optics. Vacuum. No plasma, no accretion-flow transfer, no spin.
  • Mode capture is a geometric capture map. Calling it a shadow assumes a distant, nearly uniform spherical screen. A thin equatorial source produces a different central depression (mode image).
  • Mode image is a face-on, optically thin toy model (Gralla, Holz & Wald 2019). It is not an EHT reconstruction, not Kerr, and not a fluid disk. Higher-order subrings narrower than the grid are unresolved on purpose.
  • PhotonOrbit’s \(\Delta\phi\) remains accumulated azimuth to a finite stopping surface. The curve in weak is the asymptotic \(\hat\alpha\), computed from a quadrature of the same first integral, not from that finite-camera \(\Delta\phi\).
  • Compare-mode distances are the GravitationalLensing cartoon \(1\,\mathrm{Gpc}/2\,\mathrm{Gpc}\). They are not a cosmology.

Related Programs

  • PhotonOrbit — one equatorial null geodesic. Prerequisite. This program reuses its first integral and does not replace it.
  • GravitationalLensing — thin-lens rings, doubles, diamond caustic, arcs. Prerequisite for Beat 6. It explicitly refuses black-hole silhouettes.
  • BlackHoleSpacetimeVisualizer — embeddings, tides, radial infall, Vaidya horizons. Neighbour, not a prerequisite. Its \(r_s\) circle is not a camera image.
  • RelativisticOrbit — timelike Schwarzschild geodesics. Neighbour.
  • GravitationalWaveSources — quadrupole chirp to Schwarzschild ISCO. Neighbour. No radiating EMRI is bundled into this module.
