Description

BlackHoleShadow answers a question that PhotonOrbit and GravitationalLensing do not: what does a camera actually record when it points at a black hole? PhotonOrbit already classifies a single Schwarzschild photon by its impact parameter \(b\); GravitationalLensing already maps a whole source plane onto an image plane for a transparent lens. Neither program launches a bundle of photons into a camera and asks which directions on the sky come back dark. This one does.

The spine of the lesson in two sentences:

The geometric silhouette is the disk of image-plane directions whose backward-traced Schwarzschild null geodesics are captured. Its rim is the critical curve at \(b_{\mathrm{crit}}=3\sqrt{3}\,M\), not a thin-lens Einstein ring or the coordinate circle \(r_s\).

What this program is not. It is not a Kerr movie, not an Event Horizon Telescope pipeline, and not a full fluid or radiative-transfer simulation. Although it shares mathematics with PhotonOrbit, PhotonOrbit’s object is one affine ray and its accumulated \(\Delta\phi\). It is not GravitationalLensing with \(M\) set to a black hole: the thin-lens kink \(\boldsymbol{\alpha}=\theta_E^2\boldsymbol{\theta}/\lvert\boldsymbol{\theta}\rvert^2\) cannot produce the critical null geodesic that rims the shadow. It is not RelativisticOrbit (timelike zoom-whirls stay there) and not GravitationalWaveSources (no strain, no chirp mass).
False colour. Mode image computes bolometric intensity \(I_{\mathrm{obs}}\approx\sum_{m=1}^{4} g(r_m)^4 I_{\mathrm{em}}(r_m)\) and maps it to false colours for display. Those colours are a display scale, not the spectrum of the source. Gravitational deflection is achromatic. The calculation is face-on and optically thin. Emitters are static: \(g=\sqrt{1-2M/r}\) includes gravitational redshift only, not orbital Doppler. (In Beat 5, the third panel can apply display-only spreading.)
Reading this page. Equations are rendered by MathJax from a public CDN. Without a network connection the raw \(\LaTeX\) remains visible as text. The program itself needs no internet access.

Before the first run

Unpack the program zip so you have a folder named BlackHoleShadow that contains main.py. Open a terminal in that folder. You need Python 3.10 or newer with NumPy, Matplotlib, SciPy, and mpmath. Near-critical periapsis and azimuth use mpmath at the working precision set in utilities_bhs.MP_DPS. SciPy is the primary quadrature engine for ordinary rays; mpmath is used near the critical impact parameter and when a SciPy segment cannot be trusted. High-precision work lives in utilities_bhs.py. See requirements.txt. If you do not already have that environment, follow the project-wide GFTGUX Python Setup Guide. Do not install packages into a system Python (PEP 668). Then:

python main.py --version
python main.py --mode rays

Every command on this page assumes that working directory. Even values of --n_pix are rounded up to the next odd number so a pixel sits on the optical axis. Lengths are in units of the gravitational length \(M=Gm/c^2\), where \(m\) is the black hole's physical mass.

Beat 0 · Two rays, already known

PhotonOrbit has already classified a single Schwarzschild photon. This beat repeats that classification with the same first integral so the later camera grid is visibly the same physics, not a new metric.

Null first integral (E = 1, L = b)
\[ \left(\frac{dr}{d\lambda}\right)^2 = 1 - \left(1-\frac{2M}{r}\right)\frac{b^2}{r^2}, \qquad b_{\mathrm{crit}} = 3\sqrt{3}\,M. \] 
python main.py --mode rays

The red curve at the default \(b=5\) hits \(r_s=2M\) and is reported captured. The blue curve at \(b=6\) turns at a periapsis outside the photon sphere and is reported escaped. The console \(\Delta\phi\) is accumulated azimuth to a finite stopping surface (the horizon, or twice the camera radius), exactly as in PhotonOrbit. It is not the asymptotic deflection angle \(\hat\alpha\). That distinction is Beat 7. A lambda_max status means the ray has not reached the stopping surface; increase --lambda_max (roughly \(3r_{\rm cam}\) for a distant escaper).

Beat 1 · A ray becomes a pixel

The new object is only the camera map \((b_x,b_y)\mapsto\{\text{captured},\ \text{escaped}\}\). Place the same two impact parameters on a coarse grid. Directions to captured rays are dark, while directions to escaped rays are light. Nothing about the ODE has changed.

python main.py --mode pixels

Experiments that go with this beat: EXP-2 in Suggested Experiments.

Beat 2 · The geometric shadow

A dense grid of the same classifier is a geometric capture map: a dark disk whose rim sits at the critical curve \(b_{\mathrm{crit}}\approx 5.196\,M\), not at the horizon radius \(2M\). BlackHoleSpacetimeVisualizer draws \(r_s\) as a circle in an embedding or a horizon diagram; that circle is not what a camera records. Only \(b_{\mathrm{crit}}\) is drawn on this map.

python main.py --mode capture
python main.py --mode capture --fov 24 --n_pix 201

Every pixel on this grid is a value of the impact parameter \(b\), a constant of motion measured at infinity (or, for a finite camera, an angle converted to that same constant — EXP-8 explores that conversion). The rim of the dark disk sits at \(b=b_{\rm crit}=3\sqrt3\,M\approx5.196\,M\), not at \(r=2M\) and not at \(r=3M\). Those two coordinate radii belong to a different axis entirely — Beat 6 puts both axes on the same page so the difference cannot be missed twice.

A resolution floor, not a resolution claim. The program refuses a grid on which the shadow diameter \(2b_{\rm crit}\) spans fewer than eight pixel intervals; asking for --fov 80 --n_pix 11 is refused with the shadow diameter 2 b_crit = 10.39 M spans only 1.30 grid intervals. That floor exists so a run cannot silently draw a shadow no wider than a handful of pixels and call it resolved. It is not a claim about what angular resolution a real telescope needs to see a real shadow.

Experiments that go with this beat: EXP-3 and EXP-9 in Suggested Experiments.

Beat 3 · High-winding overlay (not a photon ring)

Three names that students mix up, kept apart on purpose:

  • The photon sphere is a place in spacetime: the coordinate locus \(r=3M\), where a circular photon orbit is (unstably) possible.
  • The critical curve is a place on the sky: the image-plane circle \(b=b_{\rm crit}\), the rim of the dark disk that we had identified in Beat 2.
  • A photon ring is a bright image that appears near that curve only when emitting matter sends high-order rays to the observer.

Mode ring does not compute a photon ring. It paints a pedagogical highlighter on escaping rays whose periapsis sits near \(r=3M\) and whose asymptotic azimuth exceeds \(2\pi\). Those rays are the near-critical whirling demonstration in PhotonOrbit, shown here as a set of directions on the sky rather than as one trajectory. The orange band is that high-winding window, not a measurement of photon-ring brightness. The width of the highlighted band is chosen by educational thresholds and should not be interpreted as a measured width of a physical photon ring.

python main.py --mode ring

Experiments that go with this beat: EXP-4 in Suggested Experiments.

Beat 4 · Transfer functions \(r_m(b)\)

A face-on observer at infinity looks down on a thin equatorial emitting plane. Each impact parameter \(b\) labels a null geodesic in a meridian plane, that crosses that plane one or more times as it orbits and either escapes or falls to the horizon. That geodesic crosses the disk at orbital angles \(\pi/2\), \(3\pi/2\), \(5\pi/2\), \(\ldots\). The radii of those crossings are the transfer functions \(r_m(b)\).

In the console, we read that for the default hot-ring radius \(r_{\rm hot}=6M\), the three transfer functions equal \(r_{\rm hot}\) at \(b/M=6.9321\), \(5.4789\) and \(5.208\) respectively — three different impact parameters, converging toward \(b_{\rm crit}=5.19615\) as the crossing order rises. For this default annulus, the higher-order solutions of \(r_m(b)=r_{\rm hot}=6M\) approach \(b_{\rm crit}\) from above. These source-image locations should not be confused with all possible disk crossings, which can also occur for captured rays.

\(r_1(b)\) is the radius of a ray's first equatorial-plane crossing and supplies the direct-image contribution. A ray that crosses the plane again also has \(r_2(b)\), \(r_3(b)\), and later crossings. \(r_2\) is the lensing-ring crossing, a second pass through the disk plane on the far side of the hole. \(r_3\) and later are photon-ring / subring crossings. Rays with \(b \lt b_{\rm crit}\), traced inward from infinity, fall toward the horizon and may cross the disk first. At exactly \(b = b_{\rm crit}\), the ideal ray approaches \(r = 3M\) asymptotically and does not cross the horizon; the geometric capture map includes this measure-zero boundary in its dark mask by convention. (Note: On the Transfer functions diagram, the vertical \(b_{\mathrm{crit}}\) marker is nearly obscured by the \(r_3(b)\) transfer curve.)

python main.py --mode transfer

Beat 5 · A face-on optically thin image

Give the disk an emitted profile \(I_{\mathrm{em}}(r)\), a Gaussian annulus at \(r_{\mathrm{hot}}=6M\) by default. The observed bolometric intensity is the Gralla–Holz–Wald toy sum

Optically thin face-on image
\[ I_{\mathrm{obs}}(b)=\sum_{m=1}^{4} g(r_m)^4 I_{\mathrm{em}}(r_m),\qquad g(r)=\sqrt{1-2M/r}. \]

Mode image draws three panels: direct (\(m=1\)), plus lensing (\(m\le 2\)), plus photon-ring (\(m\ge 3\)). The figure itself labels the inferno display as false color: these colors indicate displayed intensity, not observed wavelength. There is no inclination: a correct inclined image needs three-dimensional camera/disk geometry, which is a later program.

python main.py --mode image
python main.py --mode image --r_hot 8

For an annulus at \(6M\), \(r_1\), \(r_2\), and \(r_3\) all cross the source. The later images are extremely narrow in \(b\), so their integrated flux is small even when their peak surface brightness is comparable to the direct ring. The underlying physical image is sampled at pixel centres. The first two panels display those samples unchanged; the third uses display-only subring spreading at the default --subring_spread 0.05. Set it to 0 to display the unspread third-panel raster. Narrow \(m=3,4\) peaks can miss the raster; the combined high-order peak is drawn in the radial \(I(b)\) profile under the image. The cyan critical curve is sparsely dotted so the image can show through its gaps. Peaks \(m\ge 5\) are omitted.

Display-only subring spread. The default --subring_spread 0.05 enhances the appearance of the m=3,4 bands. Setting this to 0 keeps the original point-sampled raster. The peaks have finite width; a centre need not coincide exactly with a peak, but most centres miss these extremely narrow features. Try: 
python main.py --mode image --subring_spread 0
python main.py --mode image --subring_spread 0.05
python main.py --mode image --subring_spread 0.5

The value is a radial half-width in pixel-centre spacings. For each of m=3,4, the third image panel paints a band around the location of that order's maximum in the adaptive table, using that order's peak intensity. A value of 0.05 allows a centre to miss the peak by a twentieth of a pixel spacing; 0.5 makes a much wider band. Where the two enhanced bands overlap, the lower order takes precedence: m=4 is painted first, then m=3.

This is an artificial visibility aid: it is not pixel-integrated flux, an optical blur, or a physical change in ring width.

Beat 6 · Coordinate radii are not image-plane radii

Beats 2 and 4 have now both used the symbol "radius" for two different concepts, and it is extremely easy to conflate the two. The left panel is a Schwarzschild coordinate-radius cross-section: \(r_s=2M\) and the photon sphere \(r_{\mathrm{ph}}=3M\). It is not a spacetime diagram. The right panel is the image plane: only the critical curve \(b_{\mathrm{crit}}\) is drawn on the capture map. A finite camera records an angular critical curve related to \(b_{\mathrm{crit}}\), not a ruler measurement of \(b\).

python main.py --mode radii

Beat 7 · The weak-field formula is the same ray, far away

For an escaping photon the asymptotic deflection is \(\hat\alpha=\Delta\phi_\infty-\pi\), computed from the standard \(u=1/r\) integral of the same first integral. At large \(b\)

Weak-field light deflection
\[ \hat\alpha \simeq \frac{4Gm}{c^2 b} = \frac{4M}{b}, \qquad M=Gm/c^2. \] 
python main.py --mode weak

The weak-field approximation approaches the exact curve at large \(b/M\). As \(b\) approaches \(b_{\rm crit}\) from above, the exact deflection grows without bound while \(4M/b\) stays finite. Sufficiently close to the boundary, \(\Delta \phi_{\infty}\) exceeds \(2 \pi\), and the ray completes more than one turn. A departure from the weak-field approximation alone does not imply a full turn: at \(b = 6M\), \(\Delta \phi_{\infty}\) is about 4.861 rad, less than \(2\pi\).

This is what makes higher-order images possible when a source supplies photons to bend. It is the mechanism behind a photon ring, not a photon ring by itself, since this mode does not model the presence of emitting matter.

Beat 8 · Which radius does this ring describe?

Start with two questions about one black hole: where can light orbit? and where does its capture boundary lie in the camera image? Then compare that boundary with an Einstein ring made by a distant background source.

Write \(\ell=Gm/c^2\) for the gravitational length of an object of mass \(m\). This is the quantity called \(M\) elsewhere in this Help file. The subscripts \(\ell_{\rm BH}\) and \(\ell_{\rm gal}\) distinguish the black hole from the galaxy lens.

python main.py --mode radii
python main.py --mode compare
python main.py --mode compare --logM 12.5

The first run separates the hole’s coordinate radii from its camera view. The next two print the galaxy mass and Einstein scale, then plot the logarithmic comparison. The combined illustration below uses the default galaxy mass, --logM 12; the current compare window displays the scale comparison in C.

A · Radii around the hole

The event horizon is at Schwarzschild coordinate radius \(r_s=2\ell_{\rm BH}\). The photon sphere is at \(r_{\rm ph}=3\ell_{\rm BH}\), where light can follow an unstable circular orbit. These are locations around the hole. The coordinate radius \(r\) is an areal radius: a sphere there has area \(4\pi r^2\). It is not a proper radial distance measured from the centre.

B · A radius in the camera’s impact plane

The camera labels a ray by its impact parameter \(b\), not by its distance from the hole at a particular moment. For a distant observer, the critical curve is the circle \[ b_{\rm crit}=3\sqrt{3}\,\ell_{\rm BH}\approx5.196\,\ell_{\rm BH}. \] Tracing rays inward from far away, \(b<b_{\rm crit}\) leads to capture; \(b>b_{\rm crit}\) allows scattering back out. The ideal critical ray approaches the photon sphere asymptotically.

The connection between A and B is gravitational light bending. A tangential null ray at radius \(r\) has \[ b=\frac{r}{\sqrt{1-2\ell_{\rm BH}/r}}. \] At \(r=3\ell_{\rm BH}\), this gives \(b=3\sqrt{3}\,\ell_{\rm BH}\). Thus 3 and 5.196 describe related features in different coordinates. The camera does not contain additional circles at \(b=2\ell_{\rm BH}\) and \(b=3\ell_{\rm BH}\) representing the horizon and photon sphere. The critical curve itself specifies ray geometry; a bright ring or a dark intensity image also requires an illumination model.

C · The Einstein angle and its corresponding length

In the point-mass, thin-lens model, an aligned background source is imaged into an Einstein ring of angular radius \(\theta_E\) on the observer’s sky. Its corresponding length at the lens plane is \(R_E\): \[ \theta_E=\sqrt{\frac{4\ell_{\rm gal}D_{ls}}{D_lD_s}}, \qquad R_E=D_l\theta_E. \] The second formula uses \(\theta_E\) in radians. Here the program uses the toy distances \(D_l=1\,\mathrm{Gpc}\), \(D_s=2\,\mathrm{Gpc}\), and \(D_{ls}=D_s-D_l=1\,\mathrm{Gpc}\), rather than a cosmological distance calculation.

Galaxy settingSky angle \(\theta_E\)Lens-plane length \(R_E\)\(R_E/\ell_{\rm gal}\)
--logM 12 (default)2.018 arcsec9.783 kpc204,432
--logM 12.53.588 arcsec17.397 kpc114,960

For the default run, \(R_E/\ell_{\rm gal}\approx204{,}432\), while \(b_{\rm crit}/\ell_{\rm BH}\approx5.196\). Their ratio is about 39,343. This compares the two radii in each object’s own gravitational units; it does not by itself give a ratio of their physical sizes or their angles on the same sky. A black-hole sky angle would also require its mass and observer distance.

At fixed lens distances, increasing the galaxy mass makes \(\theta_E\) and the physical \(R_E\) grow as \(\sqrt{m}\), while \(\ell_{\rm gal}\) grows as \(m\). That is why the second run has a larger angle and physical radius but a smaller \(R_E/\ell_{\rm gal}\).

“Einstein ring” does not mean “galaxy only.” A black hole can also lens a distant aligned source into an Einstein ring in its weak-field region. The distinction here is between background-source alignment and lens geometry, which set the Einstein ring, and the near-hole capture boundary, which sets \(b_{\rm crit}\). They answer different questions.

Suggested Experiments

EXP-1 · First run
Capture versus escape

Run --mode rays at the defaults, then again with --b_in 5.19 --b_out 5.21. Name the status of each ray from the console before you look at the figure.

EXP-2 · Beginner
A pixel is a direction

Run --mode pixels. Point to the dark cell and the light cell and say which trajectory from --mode rays each one represents.

EXP-3 · Beginner
The rim is not the horizon

Run --mode radii. The left panel is a coordinate-radius cross-section; the right panel is the image plane. Which circle on the right matches the dark disk, and why are \(r_s\) and \(r_{\mathrm{ph}}\) not drawn there?

EXP-4 · Intermediate
PhotonOrbit on the sky

The shadow rim is PhotonOrbit’s critical capture/escape ray. The highlighter of --mode ring is PhotonOrbit’s near-critical whirling painted as pixels. Write that sentence in your own words, then run both programs side by side.

EXP-5 · Intermediate
Recover \(4M/b\)

From the weak console line, compute the relative error of \(4M/b\) at the largest sampled \(b\). Then argue why the error must grow as you walk the curve toward \(b_{\mathrm{crit}}\).

EXP-6 · Intermediate
Two rings, two meanings

Run --mode compare. Read both plotted radii and their ratio, each in its own lens’s gravitational units. Quote \(R_E/\ell_{\rm gal}\) and \(b_{\rm crit}/\ell_{\rm BH}\), then explain the distinction between a lensing scale, an image-plane capture boundary, and a coordinate radius around the hole.

EXP-7 · Intermediate
Achromatic silhouette

Run --mode image --subring_spread 0. The palette is inferno. Write down what would change if the annulus emitted blue light instead of red while holding the emitted bolometric intensity profile fixed. (The capture map would not.) Compare the first two panels to identify the direct \(m=1\) image and the added \(m=2\) lensing image. The third adds \(m=3,4\), but without artificial spread enhancement, its sampled pixels will be scattered and may be difficult to distinguish. Use the console's table and raster maxima and the radial \(I(b)\) panel to explain why the higher-order peaks are hard to see in the image. What changes do you see with --subring_spread 0.05?

EXP-8 · Advanced
Finite camera

Rerun --mode rays with --r_cam 10 and then --r_cam 60. The capture threshold in conserved \(b\) does not move. What does move is the local angle on the camera sky. Explain using \(\sin\alpha = (b/r)\sqrt{1-2M/r}\).

EXP-9 · Advanced
Resolution contract

Try --mode capture --fov 80 --n_pix 11. Read the error. Then satisfy the contract with the smallest odd --n_pix not above 81.

EXP-10 · Advanced
Where the source images sit

Run --mode transfer. Read the three \(b(r_m=r_{\mathrm{hot}})\) values from the console. Use the interactive Matplotlib window (run without --outdir): hover over the left transfer panel and read (x, y) at the lower right of the window. The coordinates there are \(b/M\) and crossing radius \(r_m/M\). The meaning of the readout depends on the panel under the pointer: the --mode image radial panel reports \(b/M\) and pointwise image intensity, and its three face-on panels report \(b_x/M\) and \(b_y/M\). In --mode transfer the right-hand source-profile panel reports source radius \(r/M\) and emitted intensity. For this crossing question use the left-hand transfer curves, whose vertical coordinate is \(r_m/M\). Zoom near \(b_{\rm crit}\approx5.196M\) with the toolbar magnifier, or enlarge the window, so that the closely spaced curves can be distinguished at \(b=5.20M\). Saved PNGs have no live readout. At \(b=5.25M\) and \(b=5.20M\), which of the three plotted crossing curves are defined at each \(b\)? What happens to the true crossing count closer to the critical curve?

Output

Without --outdir, each mode opens a Matplotlib window (no-op if MPLBACKEND=Agg). With --outdir the program writes a timestamped PNG and a same-stem .provenance.txt and does not open a window unless --interactive is also given. The figure footer repeats Version and Build so a saved plot can be matched to this Help file. The console summary prints \(b_{\mathrm{crit}}\), statuses, and a one-line reminder of what the beat is for.

Domain of Validity

  • Schwarzschild only. Geometric optics. Vacuum. No plasma, no accretion-flow transfer, no spin.
  • Mode capture is a geometric capture map. Calling it a shadow assumes a distant, nearly uniform spherical screen. A thin equatorial source produces a different central depression (mode image).
  • Mode image is a face-on, optically thin toy model (Gralla, Holz & Wald 2019). It is not an EHT reconstruction, not Kerr, and not a fluid disk. With zero display spread, higher-order subrings narrower than a pixel may miss every pixel centre on the 2-D raster; the radial I(b) panel is the honest record of those peaks.
  • PhotonOrbit’s \(\Delta\phi\) remains accumulated azimuth to a finite stopping surface. The curve in weak is the asymptotic \(\hat\alpha\), computed from a quadrature of the same first integral, not from that finite-camera \(\Delta\phi\).
  • Compare-mode distances are the GravitationalLensing cartoon \(1\,\mathrm{Gpc}/2\,\mathrm{Gpc}\). They are not a cosmology.

  • GravitationalLensing — thin-lens rings, doubles, diamond caustic, arcs. Prerequisite for Beat 8. It explicitly refuses black-hole silhouettes.
