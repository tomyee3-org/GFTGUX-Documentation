BlackHoleShadow

Representative Sample Outputs

Current program version: 1.0.0   Build: eaf36a217f39

Purpose. These three figures survey the program's principal teaching beats. BlackHoleShadow draws the Schwarzschild capture map on the image plane, inverts face-on equatorial crossings rm(b) for a static optically thin annulus, and assembles a point-sampled image Iobs ≈ ∑ g4 Iem through m = 1..4. Lengths are in units of M.

Contents

  2. 2. Face-on transfer functions

1. Default geometric capture map

python main.py --mode capture --outdir ./figures

Beat 2. Every pixel centre with b ≤ 3√3 M is captured. The cyan circle is that critical curve. A distant spherical screen is assumed when this dark disk is called a shadow.

What it shows

  • The silhouette is a disk in the impact-parameter plane, not an Einstein ring.
  • The critical curve sits at bcrit/M = 3√3 ≈ 5.19615.
  • The event horizon (r = 2M) and photon sphere (r = 3M) are coordinate radii; they are not the same circle as this image-plane curve. Use --mode radii for that comparison.

Headline values

  • M = 1, field of view 16 M on a side (161×161 pixels).
  • Captured pixels: 8469 / 25921.
  • Minimum FOV that contains the shadow: 12.99 M.

2. Face-on transfer functions

python main.py --mode transfer --outdir ./figures

Beat 4. Left: crossing radius rm/M versus impact parameter for the first three face-on images. Right: the static Gaussian annulus used as Iem(r).

What it shows

  • One source radius maps to several image-plane radii. The dots mark where each curve crosses the default hot-ring radius rhot = 6M.
  • The m = 3 branch is already hugging bcrit.
  • Emitters are static. There is no orbital Doppler boost.

Headline values

  • Adaptive table: 192 impact parameters; 110 finite r3 samples.
  • b(rm = rhot)/M: 6.9321, 5.4789, 5.208.
  • Annulus width: 0.45 M.

3. Point-sampled face-on image

python main.py --mode image --outdir ./figures

Beat 5. Three rasters accumulate m = 1, then m ≤ 2, then m = 3,4. The radial panel is interpolated from the source-aware table; narrow photon-ring peaks may miss a pixel centre.

What it shows

  • The bright primary ring sits well outside the critical curve.
  • The lensing image (m = 2) is a thinner ring closer in.
  • Orders m = 3,4 add a sharp increment next to bcrit. That increment is obvious in I(b) and easy to miss on the raster.
  • Gravitational redshift for static emitters is g = √(1 − 2M/r), weighted as g4.

Headline values

  • g4 at rhot: 0.444444.
  • bm(rm = rhot)/M: 6.9321, 5.4789, 5.208, 5.1967.
  • Maximum table I2 and Im=3,4: 0.4457 / 0.4457.
  • Maximum raster increment from m ≥ 3: 0.07043.
  • I_obs ≈ ∑m=1..4 g4 Iem; m ≥ 5 omitted.

Notes for evaluation

  • The geometric shadow assumes a distant spherical screen of captured directions. It is not the event-horizon disk drawn at r = 2M.
  • The toy source is a static, face-on, optically thin Gaussian annulus. It is not a radiatively modeled accretion flow.
  • The model omits spin, inclination, Doppler boosting, optical depth, plasma, and time dependence.
  • Every run prints M, bcrit/M, grid size, and mode-specific diagnostics. --version prints Version and Build.
  • --outdir PATH saves a timestamped PNG and a short provenance sidecar.
