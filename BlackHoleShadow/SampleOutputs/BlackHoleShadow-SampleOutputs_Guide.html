Representative Sample Outputs

Version 1.4.1 · Build 66e118c0b45f · 2026-10-13 (CDT)

A visual and numeric companion to the Beats Help. Each figure was generated with the command printed immediately above it. Run these commands from the BlackHoleShadow folder containing main.py. The nine default runs appear first within their beats; changed settings follow.

Lengths use the black hole’s gravitational length M = Gm/c², where m is physical mass. Beat 8 uses ℓgal and ℓBH to distinguish the two lenses.

Cursor tip: In a live Matplotlib window, hover over a graph to read its (x, y) coordinates at the lower right. Saved PNGs have no live readout. Omit --outdir ./figures to open the window, or add --interactive to save and open it.

Beat 2 · The geometric shadow

A dense geometric capture map has a dark disk bounded by bcrit. Interpreting it as a shadow assumes a distant, nearly uniform spherical screen. The horizon and photon sphere are coordinate-radius features; they are not extra circles on this map.

Beat 5 · Face-on image and display spread

The source is a static, face-on, optically thin Gaussian annulus. The first two panels show direct emission and direct-plus-lensing emission. At the CLI default --subring_spread 0.05, only the third panel applies artificial visibility enhancement to the m = 3,4 bands. The radial I(b) profile and printed raster maxima use unspread data. Inferno colours represent intensity, rather than observed wavelength.

python main.py --mode image --outdir ./figures

Compare the display settings

A spread value is a radial half-width in pixel-centre spacings. Zero displays the point-sampled third panel. Positive values paint each high-order band using that order’s tabulated peak intensity, with m = 3 taking precedence over m = 4 in overlaps. This is a visibility aid, not pixel-integrated flux, an optical blur, or a physical ring width.

python main.py --mode image --subring_spread 0 --outdir ./figures
python main.py --mode image --subring_spread 0.25 --outdir ./figures
python main.py --mode image --subring_spread 8 --outdir ./figures

Beat 7 · Weak-field deflection

The exact asymptotic deflection is α̂ = Δφ∞ − π. At large b, α̂ ≃ 4Gm/(c²b) = 4M/b. The exact angle diverges as b approaches bcrit from above, while the weak-field approximation remains finite. A visible difference between the curves alone does not establish a full orbit.

Beat 8 · Which radius does this ring describe?

Each plotted radius is divided by its own lens’s gravitational length: ℓgal = Gmgal/c² or ℓBH = GmBH/c². The chart is not an overlay of circles in one physical image plane.

Interpretation and image provenance

The image model is Schwarzschild, static, face-on and optically thin. It omits spin, orbital Doppler, plasma and full accretion-flow transfer. Image orders beyond m = 4 are omitted. Narrow physical peaks can be missed by image pixel centres; inspect the unspread radial profile alongside the display.
