BlackHoleShadow 1.0.2 Release Notes

Build: f9c7252cba9e

Release Status

This Kickoff4 release follows the 1.0.1 false-color-label release and the earlier Audit20 release cycle. The author approved 1.0.0 for presentation; the supplied 1.0.1 notes record no newer individual reviewer release recommendations. Codex recommends this 1.0.2 package for Claude's independent audit. Claude has not yet reviewed this build, so no recommendation from Claude is attributed to it.

Open Bugs

No unresolved P1–P3 defect is confirmed for this build from the supplied notes and this review. This statement does not supersede the forthcoming independent audit.

Major Improvements in This Release

  • --sync-help now requires and synchronizes both BlackHoleShadow-claude.html and BlackHoleShadow-grok.html in the same documentation directory. A missing file or malformed version paragraph causes an error before either file is changed.
  • Both Beats Help files share version 1.0.2 and the same source-derived build identifier. Claude's text now limits its higher-order flux claim to the displayed teaching model and acknowledges that the physics routines can calculate higher-order crossings when explicitly requested.
  • The Sample Outputs guide now contains a new figure for each of Beats 0–8, generated from this build with the commands shown. All numerical diagnostics and intensity arrays have the same values as in 1.0.1; only source identification, Help handling, documentation and figure provenance changed.
  • The historical audit preamble in utilities_bhs.py was replaced with a short description of its current precision and classification boundaries.

Test Suite Growth

The preceding release recorded 93 tests. Version 1.0.2 has 96 tests in tests/test_physics_bhs.py. The new tests require both named Beats files, check their shared stamp and beat structure, parse and validate their displayed commands, and verify dual-file synchronization and its missing-file or malformed-stamp behavior. Run once from the program directory with MPLBACKEND=Agg python -W error::ResourceWarning -m unittest tests.test_physics_bhs -q; all 96 passed in 75.247 seconds on the review host. The 16 focused Help and Build tests also passed against the final build.

Known Limitations

  • The teaching image models a static, face-on, optically thin Gaussian annulus around a Schwarzschild hole. It does not model spin, inclination, orbital Doppler, optical depth, plasma or time dependence.
  • Image mode displays crossings through m = 4; a fixed pixel-centre raster can miss narrow higher-order peaks that appear in its adaptive radial profile. No universal flux bound is claimed for other source models.
  • The Help files obtain MathJax from an online CDN. Their prose and TeX source remain in the HTML when offline.
  • PNG and provenance sidecar publication uses ordinary single-user file I/O.

Known Minor Maintenance Items

  • The ordinary-ray float64 helpers in physics_bhs.py remain separate from the mpmath utilities; consolidating them is optional maintenance.
  • The forced SciPy fallback test covers the large-absolute-error path, but the warning-plus-relative-error path lacks an isolated trigger test.
  • High-order near-critical numerical checks make the full suite take roughly one to two minutes, depending on the host.
