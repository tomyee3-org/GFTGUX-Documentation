1. Below the critical impact parameter: capture

Figure: photon_b5_captured.png

python main.py --GM_over_c2 1.0 --r0 20.0 --b 5.0 --lambda_max 200.0 --d_lambda 0.01 --lw 1.5 --dpi 150

The photon begins at radius 20, curves around the upper side of the black hole, and reaches the event horizon at r = 2. The shaded disk marks the event horizon and the dashed circle marks the photon sphere at r = 3.

What it shows

  • With GM/c² = 1, the critical impact parameter for a photon arriving from infinity is 3√3 ≈ 5.19615.
  • The chosen value b = 5 lies below that threshold, so the initially ingoing photon cannot turn around.
  • The trajectory ends on the horizon rather than overshooting inside it because the crossing is located within the final RK4 step.
  • Paired with Sample 2, this gives a simple one-parameter comparison between capture and scattering.

Headline values

  • Status: captured.
  • Closest approach: 2.
  • Accumulated Δφ: 4.37461 rad.
  • Final affine parameter: 23.8741; 2,388 RK4 steps.

2. Above the critical impact parameter: escape

Figure: photon_b6_escaped.png

python main.py --GM_over_c2 1.0 --r0 20.0 --b 6.0 --lambda_max 200.0 --d_lambda 0.01 --lw 1.5 --dpi 150

The photon approaches from the right, turns at r ≈ 4.453, and travels outward toward the lower left. The taller data range reflects the outgoing leg reaching the program's finite escape radius, 2r₀ = 40.

What it shows

  • The turning point lies outside the dashed photon sphere.
  • The outgoing path is strongly deflected relative to a straight continuation of the incoming path.
  • Changing only b from 5 to 6 changes the outcome from capture to escape.
  • “Escaped” means the photon has turned outward and reached radius 2r₀; the program does not integrate it to infinity.

Headline values

  • Status: escaped.
  • Closest approach: 4.45336.
  • Accumulated Δφ: 4.40611 rad.
  • Final affine parameter: 63.0332; 6,304 RK4 steps.

3. Near the separatrix: a whirling escape

Figure: photon_b5.205_escaped.png

python main.py --GM_over_c2 1.0 --r0 20.0 --b 5.205 --lambda_max 400.0 --d_lambda 0.01 --lw 1.5 --dpi 150

A near-critical scattering trajectory. Its closest sampled radius is only about 0.106 above the photon sphere, and its accumulated azimuth is nearly twice that of the b = 6 case.

What it shows

  • The tight loop near the dashed circle is the characteristic near-critical “whirl.”
  • The photon spends substantial affine time close to the unstable orbit at r = 3 before escaping.
  • Small changes in b near 3√3 can sharply change both the winding and the eventual outcome.
  • This case is well suited to parameter-bracketing and step-size-convergence exercises.

Headline values

  • Status: escaped.
  • Closest sampled approach: 3.10571.
  • Accumulated Δφ: 8.72842 rad.
  • Final affine parameter: 70.4343; 7,044 RK4 steps.

4. Exactly critical: the circular photon orbit

Figure: photon_b5.196_lambda_max.png

python main.py --GM_over_c2 1.0 --r0 3.0 --b 5.196152422706632 --lambda_max 100.0 --d_lambda 0.01 --lw 1.5 --dpi 150

The trajectory repeatedly overdraws the same circle at r = 3. The accumulated Δφ corresponds to a little over nine revolutions, and the blue trajectory largely hides the dashed photon-sphere marker.

What it shows

  • At r₀ = 3 and b = 3√3, both the initial radial velocity and radial acceleration vanish.
  • The status lambda_max is the expected result here: neither capture nor escape occurs during the requested interval.
  • This circular null orbit is an unstable separatrix, not a stable photon track.
  • Decreasing b slightly at this starting radius produces capture; a higher b is not a permitted null-geodesic initial condition there.

Headline values

  • Status: lambda_max.
  • Closest approach: 3.
  • Accumulated Δφ: 57.735 rad.
  • Final affine parameter: 100; 10,000 RK4 steps.

Notes for evaluation

  • The plot marks the event horizon, photon sphere, trajectory, and concise run diagnostics in a single view.
  • The reported Δφ is the accumulated Schwarzschild-coordinate azimuth between finite start and stop surfaces, not the conventional asymptotic light-deflection angle.
  • Horizon and escape crossings are linearly located within the last RK4 step. Closest approach is the smallest sampled radius rather than an interpolated turning point, so its final digits can vary slightly in convergence studies.
  • Every --outdir run saves a PNG and a provenance sidecar containing lossless input values and a ready-to-copy reproduction command.
  • The supplied current build passes all 123 regression tests, including the run with runtime warnings promoted to errors.
  • The Help file extends these examples with exercises on radial infall, finite-radius starts inside the photon sphere, scale invariance, threshold bracketing, tangential launches, and numerical convergence.
