Outward launch that turns back: capture

python main.py --r0 2.5 --b 5.3 --direction outward --outdir ./figures

Initial outward motion does not guarantee escape.

What it shows

  • With r0=2.5 and b=5.3, the ray starts outward.
  • It turns near r=2.70323, inside the photon sphere, then reaches the horizon.
  • The parameter controls the initial radial velocity; subsequent turns follow the same geodesic equations.

Headline values

  • Initial direction: outward
  • Status: captured
  • Sampled closest radius: 2
  • Accumulated azimuth: 3.16771 rad
  • Final affine parameter: 3.86466 (of 200 requested)

Notes for evaluation

  • All figures were generated with the current build on Linux, Python 3.12.14, NumPy 2.3.5 and Matplotlib 3.10.8. The PNGs were converted to 256-colour indexed images and embedded here.
  • Existing commands without --direction use inward initial motion. At zero initial radial speed, both choices give the same tangential state.
  • The equations and positive angular momentum are unchanged. The new option chooses the initial radial-velocity root, not the order of plotted samples.
  • The closest radius is sampled; horizon and escape crossings use linear interpolation within the last RK4 step. Delta phi is accumulated finite-interval coordinate azimuth, not an asymptotic deflection angle.

Original PNGs, provenance and console records are included under Verification/SampleRuns in the update package.
