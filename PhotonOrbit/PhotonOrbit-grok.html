Get ready

Use Python 3.10+ and Matplotlib. Run from the folder with main.py. Try python main.py --help if a flag is unfamiliar. Each command below opens a plot and saves a PNG and provenance sidecar under ./figures. The SampleOutputs Guide shows the four current-build figures.

One question: When does an inward-going light ray escape, and what does the plotted winding really measure?

0 · Cross the horizon

Before the run: b=5 is below 3√3≈5.19615. Point to the dashed r=3 photon sphere and the filled r=2 horizon. Predict capture or escape.

python main.py --GM_over_c2 1.0 --r0 20.0 --b 5.0 --lambda_max 200.0 --d_lambda 0.01 --lw 1.5 --dpi 150 --outdir ./figures

Read: status captured; closest radius 2; Δφ=4.37461 rad; final affine parameter 23.8741. The blue curve ends at the horizon, which is located within the last step. Capture does not give an asymptotic deflection angle.

Write down: Which printed field tells you the outcome, and which shows how much Schwarzschild-coordinate azimuth accumulated before it?

1 · Make it turn back

Before the run: Change only b to 6. Predict where the closest point lies relative to r=3.

python main.py --GM_over_c2 1.0 --r0 20.0 --b 6.0 --lambda_max 200.0 --d_lambda 0.01 --lw 1.5 --dpi 150 --outdir ./figures

Read: status escaped; sampled closest radius 4.45336; Δφ=4.40611 rad. Follow the path outward to the program's finite escape radius 2r0=40; “escaped” does not mean the calculation reached infinity.

Write down: What changed between Beat 0 and Beat 1 besides the outcome? Keep the finite starting radius r0=20 in mind.

2 · Approach the dividing line

Before the run: Use b=5.205, just above critical. Guess whether the ray escapes immediately or loops near r=3.

python main.py --GM_over_c2 1.0 --r0 20.0 --b 5.205 --lambda_max 400.0 --d_lambda 0.01 --lw 1.5 --dpi 150 --outdir ./figures

Read: it escapes after a whirl: sampled closest radius 3.10571, Δφ=8.72842 rad, final affine parameter 70.4343. Compare with Beat 1's Δφ at the same r0 and RK4 step size.

Try: Repeat with --d_lambda 0.02 and 0.005. Compare Δφ and the event-located final affine parameter; the sampled minimum radius need not improve monotonically in its last digits.

3 · Balance at the photon sphere

Before the run: Set r0=3 and copy the full-precision b=3√3. What should the initial radial acceleration be?

python main.py --GM_over_c2 1.0 --r0 3.0 --b 5.196152422706632 --lambda_max 100.0 --d_lambda 0.01 --lw 1.5 --dpi 150 --outdir ./figures

Read: status lambda_max, radius 3, Δφ=57.735 rad over 100 affine units. It circles about 9.19 times during this finite run. lambda_max is a time cutoff, not a surface in space; this orbit is unstable.

Try: Decrease b to 5.196152 at the same r0: capture. A sufficiently larger b is an invalid initial condition. The code tolerates a few floating-point ulps just over the bound; do not assign that band physical meaning.

Try it yourself · one change per run

  1. python main.py --b 0. Why is the blue path straight, and why is Δφ=0?
  2. python main.py --r0 2.5 --b 3. Between horizon and photon sphere, can an initially ingoing allowed ray turn back?
  3. At fixed r0=20, bracket the transition with --b 5.19 and --b 5.20. Narrow the bracket; give both status and step size.
  4. Compare --b 6 with --b 5.205 at the same r0 and --d_lambda. Which field quantifies the extra winding?
  5. Repeat Beat 1 with all lengths and affine settings multiplied by ten: --GM_over_c2 10 --r0 200 --b 60 --lambda_max 2000 --d_lambda 0.1. Which dimensionless angular diagnostic stays the same?
  6. Run python main.py --r0 6 --b 7.3484692283495345 and python main.py --r0 2.5 --b 5.590169943749475. Both start tangentially. Why do their statuses differ? Use the radial acceleration's sign.

Governing Equations

In units with E=1 and L=b≥0, (dr/dλ)² = 1 − (b²/r²)(1−2M/r), d²r/dλ² = (b²/r³)(1−3M/r), and dφ/dλ=b/r², where M=GM/c². The event horizon is 2M, the photon sphere 3M, and the critical impact parameter for infinity launch 3√3 M. At finite r0, only a locally allowed range of b can start with real inward or tangential velocity.

Algorithm and flags

A fourth-order Runge–Kutta step advances radial position, radial velocity and azimuth. A crossing of r=2M or the outbound escape radius 2r0 is linearly located within the last step. The closest radius is a sampled minimum. --GM_over_c2, --r0, --b, --lambda_max, --d_lambda, --lw, --dpi, --outdir, --help and --version are the available controls. The console gives status, closest approach, Δφ, steps, and final affine parameter. A saved PNG has a text provenance sidecar and a lossless reproduction command; Matplotlib environment and style are not recorded, so pixels need not be identical across machines.

Domain of Validity

Educational equatorial Schwarzschild null geodesics only: no spin, plasma or multi-ray imaging. “Escaped” stops at finite 2r0; Δφ is finite-interval Schwarzschild-coordinate azimuth, not the asymptotic deflection angle. The circular orbit is unstable. Event crossing uses linear interpolation even though the underlying step uses RK4. Closest approach is not interpolated. A few ulps above the computed local bound may be accepted as tangential by the floating-point tolerance; that does not add a physical solution. If an event is not reached by lambda_max, status records the cutoff rather than a third physical destination.
